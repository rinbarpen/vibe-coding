# 医学论文图表与排版规范指南

## 1. 表格规范：三线表 (Three-line Table)

医学论文中表格必须使用标准的“三线表”格式。

### 核心要求
- **结构**: 仅保留顶线、栏目线（表头下线）和底线。严禁使用纵线和斜线。
- **表题**: 位于表格上方，中英文对照（视期刊要求）。
- **单位**: 量和单位应齐全，放在栏目项后或表头下。
- **注释**: 表格下方的注释用 `*` 或 `a, b, c` 标注，解释缩写或统计学意义。

### Markdown 示例
```markdown
表1 两组患者基线资料比较 [Table 1 Comparison of baseline data between two groups]
------------------------------------------------------------
组别 (Group)    例数 (n)    年龄 (岁, Mean±SD)    性别 (男/女)
------------------------------------------------------------
观察组 (Obs)      50          65.4±8.2            28/22
对照组 (Ctrl)     50          64.8±7.9            26/24
------------------------------------------------------------
注：t=0.375, P=0.708。
```

## 2. 图像规范 (Image Requirements)

### 核心要求
- **分辨率**: 彩图不低于 300 dpi，黑白图（如显微镜图）不低于 600 dpi，线条图不低于 1000 dpi。
- **标注**: 图中文字使用 Arial 或 Helvetica 字体，字号通常为 8 pt。
- **比例尺**: 显微照片必须包含标尺 (Scale bar)，严禁仅在图注中写“放大倍数”。
- **组合图**: 多个子图用 A, B, C 标注在左上角。

### 图注要求
- 位于图像下方。
- 必须包含：图序、图题、图中符号说明、统计学意义。

## 3. 文字排版方式 (Typography)

### 字体与字号
- **中文**: 正文通常使用宋体，标题使用黑体。
- **英文**: 使用 Times New Roman。
- **字号**: 正文一般为小四或五号字。

### 间距与对齐
- **行间距**: 通常为 1.5 倍或 2 倍行距（视投稿要求）。
- **对齐方式**: 两端对齐，段首缩进 2 个字符。

### 数学公式与单位
- **单位**: 必须使用国际标准单位（如 μmol/L 而非 umol/L）。单位与数值间留一个半角空格（百分号 % 和度数 ° 除外）。
- **公式**: 复杂公式建议使用 LaTeX 格式。
    - 示例：$P = \frac{n}{N} \times 100\%$

# 医学摘要润色与对齐指南

## 1. 结构化摘要规范 (Structured Abstract)

中英文摘要必须严格对应，包含以下四个部分：

- **目的 (Objective / Purpose)**: 简洁陈述研究背景及核心目的。
- **方法 (Methods)**: 简述研究对象、分组、干预措施及主要观察指标。
- **结果 (Results)**: 列出关键数据、P值及统计学意义。
- **结论 (Conclusion)**: 基于结果得出的临床启示或总结。

## 2. 润色要点

### 中文摘要润色
- **专业术语**: 确保使用标准的医学名词。
- **句式优化**: 避免口语化，使用“回顾性分析”、“具有统计学意义”等标准表达。
- **逻辑连贯**: 确保因果关系明确。

### 英文摘要润色
- **时态规范**: 
    - 目的：一般现在时或一般过去时。
    - 方法与结果：一般过去时（因为研究已完成）。
    - 结论：一般现在时（陈述普遍真理或当前观点）。
- **语态选择**: 
    - 方法部分多用被动语态 (e.g., "Patients were divided into...")。
    - 结果部分可用主动语态 (e.g., "The results showed that...")。
- **词汇地道**: 
    - 避免 "very", "good" 等模糊词汇。
    - 使用 "significant", "substantial", "efficacious", "adverse events" 等专业词汇。

## 3. 中英对齐检查清单
- [ ] 标题 (Title) 是否含义一致？
- [ ] 作者姓名拼音是否符合规范？
- [ ] 关键词 (Keywords) 是否一一对应且符合 MeSH 标准？
- [ ] 摘要中的数据（样本量、百分比、P值）是否完全一致？
- [ ] 英文摘要是否遗漏了中文摘要中的核心发现？

## 4. 常用对齐短语
- **目的**: "To investigate the effect of..." / "本研究旨在探讨..."
- **方法**: "A total of [N] patients were enrolled..." / "选取 [N] 例患者..."
- **结果**: "There was a significant difference between..." / "两组间差异具有统计学意义..."
- **结论**: "[Treatment] is safe and effective for..." / "[疗法] 对 [疾病] 安全有效。"

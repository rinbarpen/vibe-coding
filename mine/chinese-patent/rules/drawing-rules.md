# 中国专利附图绘制规则

> **重要**：本文件为中文专利申请的附图绘制权威规则。在不冲突的情况下，同时遵守 [../reference.md](../reference.md) 中的附图规范。当本文件与 reference.md 冲突时，**本文件优先**。

## 核心规则：中文文本要求（强制）

**所有附图内的标注文字必须使用中文。**

本规则覆盖 reference.md 第 107 行「图片内的标注文字应使用英文」的规定。

### 允许的例外
以下情况可以使用非中文文本：
- 数学符号（如 α、β、Σ、∫）
- 国际标准单位（mm、Hz、dB、V、A 等）
- 国际通用技术缩写（CPU、API、USB、I/O、HTTP、TCP/IP 等）
- 商品型号或专有名称（如 iPhone、DDR5）

### 违反判断标准
- 任何非读者可自然理解的中文词汇出现在图内即为不符合要求
- 「使用英文缩写是行业惯例」只有在缩写确实是国际通行且无合理中文等效项时才成立

## 字体规范

### Draw.io（结构图/关系图/流程图）
- 正文标注：宋体 (SimSun)，15px
- 模块/区域标题：黑体 (SimHei)，15px
- 回退字体：WenQuanYi Micro Hei → Noto Sans CJK SC → 系统默认中文字体

### Matplotlib（数据图/统计图）
```python
import matplotlib.pyplot as plt
plt.rcParams['font.sans-serif'] = ['SimHei', 'WenQuanYi Micro Hei', 'Noto Sans CJK SC']
plt.rcParams['axes.unicode_minus'] = False
```
- 坐标轴标签、图例、标题、注释：中文，SimHei 优先
- 字号：按图形大小比例设置，确保可读性

## 视觉风格

- **颜色**：仅黑白色（B&W），不使用彩色
- **连接线**：正交走线（直角转折），实线为主连接，虚线为数据流
- **形状**：模块使用圆角矩形，决策使用菱形，步骤使用矩形
- **禁止**：阴影、渐变、3D 效果、背景色

## 尺寸与分辨率

- **最大物理尺寸**：165mm（宽）× 245mm（高）
- **分辨率**：72-300 DPI，推荐 300 DPI 以确保申请稿清晰度
- **输出格式**：PNG（优先）或 JPEG

## 图注规则

- **图号（图1、图2等）严禁出现在图片像素内**
- **图注必须放在图片下方**，使用 HTML `<figcaption>图N 描述</figcaption>` 格式
- **图中不得包含任何形式的图号或图题文字**

## 文件命名

- 文件名格式：`images/图N.png`（N 为附图编号）
- 编号必须与附图说明和正文引用一致

## 按图类型分类规则

### 结构示意图
- 使用 Draw.io 生成
- 圆角矩形表示模块，实线边框
- 正交连接线表示模块间关系
- 模块内可含子模块，用虚线边框区分

### 方法流程图
- 使用 Draw.io 生成
- 矩形表示步骤，菱形表示判断分支
- 箭头表示流程方向（默认从上到下或从左到右）
- 步骤文字简洁（建议 ≤10 字）

### 电路/连接图
- 使用 Draw.io 生成
- 标准元件符号，正交布线
- 关键节点标注中文说明

### 数据图（曲线/统计图）
- 使用 Matplotlib 生成
- 坐标轴标签使用中文
- B&W 环境下使用线型（实线、虚线、点线）和填充图案区分数据序列
- 曲线图禁止纯颜色区分（发表后可能转为灰度）

## 生成后验证清单

生成每张图后必须检查：
- [ ] 图中所有标注文字为中文（允许例外见上）
- [ ] 图中无图号（图1、图2等）
- [ ] 图中无图注（图注在 HTML 文档中）
- [ ] 符合 B&W 要求
- [ ] 尺寸在 165mm × 245mm 以内
- [ ] 分辨率在 72-300 DPI
- [ ] 文件名正确：`images/图N.png`
- [ ] 图片清晰可读，文字无截断

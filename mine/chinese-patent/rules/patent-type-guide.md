# 专利类型判定指南

## 中国专利三种类型

### 发明专利
- **保护对象**：产品、方法、工艺、用途（包括软件、算法、商业方法、化学物质）
- **保护期限**：20 年（自申请日起）
- **审查特点**：实质审查制，审查周期 2-3 年
- **创造性要求**：突出的实质性特点和显著的进步

### 实用新型专利
- **保护对象**：产品的形状、构造或其结合（不保护方法、软件）
- **保护期限**：10 年（自申请日起）
- **审查特点**：初步审查制（仅形式审查），授权快（6-12 个月）
- **创造性要求**：实质性特点和进步（低于发明的要求）
- **注意**：不保护无确定形状的产品（流体、粉末等）

### 外观设计专利
- **保护对象**：产品的形状、图案、色彩及其结合，富有美感并适于工业应用
- **保护期限**：15 年（自申请日起）
- **审查特点**：初步审查制
- **注意**：本技能主要处理发明和实用新型的说明书撰写

## 自动判定决策树

当用户未明确指定专利类型时，按以下规则自动判定：

```
1. 是否为方法/工艺/用途/软件/算法？
   → 是 → 发明专利
   → 否 → 继续

2. 是否为产品外观/图案/色彩设计？
   → 是 → 外观设计专利（本技能不覆盖）
   → 否 → 继续

3. 是否为产品的形状/结构改进，且创造性不高？
   → 是 → 实用新型专利（可选：发明+实用新型同日申请）
   → 否 → 发明专利

4. 无法明确判定？
   → 默认推荐发明专利（保护范围最广）
```

## 同日申请策略

当技术方案同时满足发明和实用新型的要求时，可建议同日申请：
- 实用新型先授权（约 1 年），获得快速保护
- 发明专利随后审查，授权后放弃实用新型
- 适合有快速维权需求的技术方案

## 判定输出格式

在 plan 输出中应包含：
- **专利类型**：发明 / 实用新型 / 同日申请
- **判定依据**：简要说明判定理由（1-2 句）
- **备用方案**：可选的其他类型建议

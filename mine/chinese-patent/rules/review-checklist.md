# 中国专利说明书审阅检查清单

> 本文件是审阅中国专利说明书的完整检查清单。审阅子技能（review）必须逐项检查。

## 审阅维度

### 1. 结构完整性
- [ ] 技术领域已填写
- [ ] 背景技术已填写
- [ ] 发明内容包含要解决的技术问题、技术方案、有益效果
- [ ] 附图说明与附图和正文引用一一对应
- [ ] 具体实施方式结合附图详细描述
- [ ] 权利要求书包含独立权利要求和从属权利要求
- [ ] 摘要已填写，300 字以内

### 2. 术语一致性
- [ ] 说明书与权利要求书关键术语一致
- [ ] 同一篇内统一使用「本发明」或「本申请」，不混用
- [ ] 无同义混用导致歧义
- [ ] 数字、单位、符号使用一致

### 3. 附图对应性
- [ ] 附图说明与 images/ 中文件名一致
- [ ] 附图编号（图1、图2……）在附图说明、正文引用、文件名中一致
- [ ] 图片路径使用本地相对路径，非 HTTP URL
- [ ] 附图总数量与附图说明条目数一致

### 4. 用语规范
- [ ] 无商业性、宣传性用语（如「领先」「最佳」）
- [ ] 背景技术客观描述，不贬低他人
- [ ] 无广告语或主观评价

### 5. 实质性检查
- [ ] 背景技术明确指出现有技术的不足之处
- [ ] 技术问题、技术方案、有益效果三者逻辑对应
- [ ] 具体实施方式充分支持权利要求范围
- [ ] 独立权利要求包含必要技术特征
- [ ] 具体实施方式使本领域技术人员能够实现

### 6. 格式合规
- [ ] 图片分辨率在 72-300 DPI 之间
- [ ] 图片尺寸不超过 165mm × 245mm
- [ ] 图号（图1、图2等）不在图片像素内
- [ ] 图注在文档中图片下方，不在图片像素内
- [ ] 表格有实线边框
- [ ] 数学公式使用 LaTeX 格式（`\(...\)` 或 `$$...$$`）

### 7. 可导出性检查
- [ ] HTML 文件格式良好
- [ ] 所有图片路径可解析
- [ ] LaTeX 数学表达格式正确，可被 pandoc 识别
- [ ] 无外部 HTTP 图片链接

## 常见错误速查

| 问题 | 严重程度 | 修复建议 |
|------|---------|---------|
| 说明书与权利要求用语不一致 | 必须改 | 先定权利要求用语，再在说明书中统一 |
| 附图说明与附图不对应 | 必须改 | 按图号顺序写附图说明，与 images/ 文件名一致 |
| 具体实施方式过于笼统 | 必须改 | 结合附图写清结构、连接关系或步骤细节 |
| 图片用 HTTP URL | 必须改 | 替换为本地路径（如 images/图1.png） |
| 图片像素内包含图号图注 | 必须改 | 删除图中的图号图注，移至 HTML `<figcaption>` |
| 缺少权利要求书或摘要 | 必须改 | 补充对应章节 |
| 数学公式未用 LaTeX | 必须改 | 转换为 `\(...\)` 或 `$$...$$` |
| 独立权利要求不完整 | 必须改 | 确保包含全部必要技术特征 |
| 术语混用（本发明/本申请） | 建议改 | 全文统一表述 |
| 背景技术含广告语或主观评价 | 建议改 | 改为客观技术描述 |
| 摘要超过 300 字 | 建议改 | 精简至 300 字以内 |
| 附图说明展开过多技术细节 | 建议改 | 将技术细节移至具体实施方式 |
| 段落无首行缩进 | 建议改 | 添加 CSS `text-indent: 2em` |
| 缺少多个实施例 | 建议改 | 增加变形例以扩展保护范围 |

## 审阅严重级别

| 级别 | 含义 | 行动 |
|------|------|------|
| **必须改** | 影响授权或合规的严重问题 | 修复后才能导出 docx |
| **建议改** | 提升质量或减少审查意见 | 建议修复，不阻断流程 |

## 审阅报告输出格式

```markdown
## 审阅报告

### 总体评估：[通过 / 有条件通过 / 不通过]

### 【必须改】问题
1. [问题描述] — [建议修复方案]
2. ...

### 【建议改】问题
1. [问题描述] — [建议修复方案]
2. ...

### 通过标准
- 无「必须改」问题 → 可通过，导出 docx
- 有「必须改」问题 → 修复后重新审阅
```

# 中国专利规划 (Chinese Patent Plan)

分析发明内容，自动判定专利类型，输出结构化撰写计划。

## 何时使用

- 用户要求：规划专利、分析发明、确定专利类型、起草专利大纲
- 关键词：专利规划、专利大纲、判定类型、发明分析、权利要求起草
- 作为 `chinese-patent-pipeline` 的第一步

## 输入来源

可从以下任意形式接收发明信息：
- 自然语言描述（口头说明、简短想法）
- 会议记录或技术交底文档
- 已有的产品规格或技术方案文档
- 在代理对话中直接描述发明

## 工作流程

### Step 1: 理解发明
从用户输入中提取：
- 技术领域
- 要解决的技术问题
- 技术方案（核心创新点）
- 带来的有益效果

如信息不足，主动提问补充。

### Step 2: 判定专利类型
参考 `../rules/patent-type-guide.md` 的决策树：

```
方法/工艺/软件/算法？ → 发明专利
产品形状/结构改进？   → 发明 or 实用新型
产品外观设计？        → 外观设计（本技能不覆盖）
无法判定？            → 默认发明专利
```

如用户明确指定类型，按用户指定执行，但仍给出分析和建议。

### Step 3: 确定关键技术特征
- 区别技术特征：与现有技术相比的创新点
- 必要技术特征：实现发明所必需的要素
- 附加技术特征：可选优化项（用于从属权利要求）

### Step 4: 起草权利要求结构
- 独立权利要求 1：包含全部必要技术特征
- 从属权利要求 2..N：每个增加一项附加技术特征
- 每个权利要求用一句话描述

### Step 5: 确定附图需求
列出需要绘制的所有附图：
- 结构示意图（系统/模块/电路结构）→ 使用 drawio
- 方法流程图（处理步骤/控制逻辑）→ 使用 drawio
- 数据图（性能对比/实验结果）→ 使用 matplotlib

每张图包含：图号、类型、简要描述。

### Step 6: 输出规划文档

## 输出格式

```markdown
## 专利规划文档

### 基本信息
- **专利名称**：[名称]
- **专利类型**：发明 / 实用新型 / 同日申请
- **判定依据**：[1-2 句理由]

### 技术概述
- **技术领域**：[领域描述]
- **要解决的技术问题**：[问题描述]
- **技术方案概要**：[方案概括]
- **有益效果**：[效果列表]

### 权利要求结构
1. 独立权利要求：[概括]
   - 1.1 [必要技术特征 A]
   - 1.2 [必要技术特征 B]
   - 1.3 [必要技术特征 C]
2. 从属权利要求 2：[附加特征概括]
3. 从属权利要求 3：[附加特征概括]
...

### 附图清单
| 图号 | 类型 | 描述 | 绘制工具 |
|------|------|------|---------|
| 图1 | 结构示意图 | [描述] | drawio |
| 图2 | 流程图 | [描述] | drawio |
| 图3 | 数据图 | [描述] | matplotlib |

### 各章节要点
- **技术领域**：[要点]
- **背景技术**：[要点与拟引用现有技术]
- **发明内容**：[每个子节的要点]
- **具体实施方式**：[实施例结构与附图对应关系]
```

## 注意事项

- 如用户信息不足，先提问再输出规划，不要编造
- 同日申请（发明+实用新型）仅在明确有快速维权需求时建议
- 判定类型后给出 1-2 句理由，让用户确认后再继续

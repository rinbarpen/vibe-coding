# 医学 AI 投稿渠道参考 (Med-AI Venues)

本文件汇总了医学与 AI 交叉方向的主流投稿渠道及其核心偏好。

## 1. 顶级医学期刊 (Clinical Focus)

这些期刊对临床价值和验证严谨性要求极高，技术细节通常放在附录。

| 期刊 | 偏好 | 关键要求 |
| :--- | :--- | :--- |
| **Nature Medicine** | 突破性的临床应用 | 必须有外部验证，最好有前瞻性临床试验。 |
| **The Lancet Digital Health** | 数字化医疗的实际影响 | 强调对医疗流程的改变和大规模人群验证。 |
| **JAMA Network Open** | 临床流行病学与 AI | 侧重于 AI 在特定疾病诊断/预后中的应用。 |

## 2. 顶级 AI/工程期刊 (Technical Focus)

这些期刊平衡技术创新与医学应用。

| 期刊 | 偏好 | 关键要求 |
| :--- | :--- | :--- |
| **IEEE TMI** | 医学影像处理算法 | 强调数学严谨性、物理模型结合及算法创新。 |
| **Medical Image Analysis** | 深度学习与医学影像 | 侧重于计算机视觉在医学领域的深度应用。 |
| **Nature Machine Intelligence** | 跨学科 AI 研究 | 强调 AI 方法论的通用性及其在医学中的独特贡献。 |

## 3. 顶级会议 (Fast-paced Innovation)

| 会议 | 偏好 | 关键要求 |
| :--- | :--- | :--- |
| **MICCAI** | 医学影像计算与干预 | 每年 3-4 月投稿，强调算法在特定医学任务上的表现。 |
| **ISBI** | 生物医学成像 | 侧重于成像技术与信号处理。 |
| **CHIL** | 机器学习与健康 | 侧重于机器学习在临床决策支持中的应用。 |

## 4. 格式转换建议 (Conversion)

-   **MICCAI → IEEE TMI**: 将 8 页会议论文扩展为 10-12 页期刊论文。增加更多的消融实验、更深入的数学推导以及更广泛的数据集验证。
-   **AI Conference → Clinical Journal**: 彻底重写 Introduction 和 Discussion，将重心从“算法 SOTA”转向“临床痛点解决”。将复杂的网络结构图移至附录，将临床指标（Sensitivity, Specificity）移至主文。
-   **通用要求**: 无论投向何处，必须包含 **Ethics Statement** 和 **Data Availability Statement**。

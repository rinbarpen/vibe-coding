# Research Figure Prompt Templates

Use the shared contract in `SKILL.md`, then select the closest template. Keep
the visible text list exhaustive and the scientific boundary explicit.

## Technical route / workflow

`Show the research problem, 3–6 documented steps, outputs, and validation in a
left-to-right academic workflow. Use only these labels: [LABELS]. Arrows mean
[RELATIONS]; feedback is [PRESENT/ABSENT]. Do not invent steps, metrics, or
results. Clean vector-like layout, restrained palette, publication typography.`

## Experimental setup

`Draw the documented apparatus with the central device, inputs, outputs,
measurement points, and data-collection module. Use only components [PARTS].
Show material flow, gas flow, signal, and data links exactly as [CONNECTIONS].
Simplified academic schematic; no product advertising, photorealistic metal,
or unreported equipment.`

## Mechanism

`Explain [PHENOMENON] as a causal chain across [ENTITIES]. Use arrow semantics:
activation [STYLE], inhibition [STYLE], migration/transfer [STYLE], feedback
[STYLE]. Include only [VISIBLE_TERMS]; no unreported mechanism, parameter, or
quantitative result.`

## Multi-panel comparison

`Create [N] panels in [LAYOUT], numbered (a)…([N]). Compare [GROUPS] with the
same viewpoint, scale, typography, palette, margins, and legend. Real values
are supplied in [DATA]; where absent, use qualitative objects only—no numeric
axes, curves, colorbars, or significance marks.`

## Graphical abstract

`Make the contribution [CONTRIBUTION] immediately legible with [HIERARCHY]
reading order. Use [OBJECTS] and [PALETTE], leave whitespace for [CAPTION/TITLE]
if needed, and include only [VISIBLE_TEXT]. Academic editorial illustration,
not a commercial poster; do not imply unverified efficacy.`

## Presentation overview

`Summarize the project as a readable overview: motivation [MOTIVATION], phases
[PHASES], outputs [OUTPUTS], and dependencies [RELATIONS]. Use a clear hierarchy
for a projected slide, short labels only, and no invented claims or metrics.`

## Journal cover

`Translate the documented insight [INSIGHT] into an editorial scientific visual
metaphor using [OBJECTS], [DEPTH], and [PALETTE]. Preserve scientific identity
without implying an unmeasured result; leave intentional negative space for
cover text and include only [VISIBLE_TEXT].`

## Local edit commands

- `Replace [OLD] with [NEW] without changing layout or labels.`
- `Correct [TYPO] to [TEXT]; preserve all other pixels and typography.`
- `Make [REGION] [COLOR/STYLE]; keep arrow direction and panel numbering.`
- `Remove [ELEMENT] and close the gap without moving neighboring modules.`

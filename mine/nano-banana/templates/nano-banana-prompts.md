# Nano Banana Pro Prompt Templates

Copy-paste prompt templates organized by category. Replace `[placeholders]` with your content.
Add quality boosters for v2, keep concise for v1.

---

## Photo-Realistic

### Portrait
```
[Person description — age, gender, appearance], [expression and pose], [clothing style], [setting/background], [lighting — natural window light, studio, golden hour], [color palette — warm, cool, neutral], shot on [lens — 85mm, 50mm] prime lens, [depth of field — shallow, deep]. Professional portrait photography, sharp focus on eyes, 8k detail.
```

### Interior Scene
```
[Room type and style — modern, minimalist, rustic, industrial], [key furniture and elements], [color scheme], [lighting source and quality], [time of day], shot on wide angle lens, interior design photography, highly detailed, warm atmosphere, architectural digest quality.
```

### Urban / Street
```
[City/scene description], [time of day], [weather], [specific details — people, vehicles, architecture, signs], [mood], street photography style, [lens — 35mm, 50mm], candid feel, cinematic color grading, photojournalistic quality.
```

### Nature / Wildlife
```
[Subject — animal, plant, landscape element], [habitat/environment], [behavior/action], [lighting conditions], [season], wildlife photography, [lens — telephoto, macro], National Geographic quality, sharp details, natural colors.
```

## Quick v2 Quality Boosters

Append these to any prompt for higher quality (v2 only):

```
highly detailed, sharp focus, professional composition, 8k resolution, masterpiece quality, trending on ArtStation, cinematic lighting, award-winning photography
```

## Quick v1 Concise Templates

Keep v1 prompts short and focused:

```
[Subject], [style], [2-3 key details], [lighting], [mood]. High quality.
```

Examples:
```
Cat sleeping on windowsill, watercolor style, rain on glass, warm lamp, cozy. High quality.
Modern kitchen interior, photorealistic, marble counters, pendant lights, morning sun. High quality.
```

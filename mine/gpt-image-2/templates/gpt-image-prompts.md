# GPT-Image-2 Prompt Templates

Copy-paste prompt templates organized by image category. Replace `[placeholders]` with your content.

---

## Illustration

### Storybook / Children's Book
```
A charming illustration of [subject], [setting], watercolor and ink style, soft pastel colors, gentle lighting, storybook aesthetic, whimsical mood. No text.
```

### Editorial Illustration
```
An editorial illustration about [topic/concept], flat vector style, bold geometric shapes, [color palette: 3-4 colors], clean composition, modern design. Negative space for text overlay on [left/right/top].
```

### Fantasy / Sci-Fi
```
A [fantasy/sci-fi] illustration of [subject], epic scale, dramatic lighting, [specific details about world/creatures/technology], concept art style, rich color palette, cinematic wide shot.
```

## Logo & Icon

### Logo Concept
```
Logo design concept for [brand/company name]: [brief — what the brand does], [style — minimalist, vintage, geometric, wordmark, etc.], [key symbol or motif], [color palette], clean vector style, on white background. No text other than the logo itself. Professional brand identity quality.
```

### App Icon
```
App icon design for [app name]: [purpose of app], [key visual metaphor], [style — flat, gradient, glassmorphism, skeuomorphic], vibrant colors, rounded corners, iOS/Android app icon format. Centered composition, recognizable at small sizes. No text.
```

### Favicon / Simple Icon
```
Simple icon: [subject], minimalist, single color, solid silhouette style, centered on white background, scalable vector aesthetic. Clean lines, no text, recognizable at 16x16 pixels.
```

## Diagram / Infographic (Non-Technical)

### Visual Diagram
```
A clean visual diagram explaining [concept], isometric 3D style, [key elements labeled visually], organized layout, corporate color palette of [colors], modern infographic style, white background. Text should be minimal — visual communication first.
```

### Comparison Visual
```
A visual comparison showing [A] vs [B], split composition left and right, [visual elements representing each side], balanced layout, [color scheme — warm vs cool tones], educational infographic style, clear visual hierarchy. Minimal text labels.
```

### Timeline Visual
```
A visual timeline of [topic/history], horizontal layout, [number of] key milestones with simple icon for each, gradient color progression from past to present, clean minimalist infographic style, white background. Text labels minimal.
```

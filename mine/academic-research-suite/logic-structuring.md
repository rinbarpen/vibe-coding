# Academic Logic Structuring: 逻辑架构与大纲

## 核心任务
1. **架构设计**：根据目标期刊或基金类别选择合适的模板（如 IMRaD, NSFC）。
2. **Storyline 构建**：理清“为什么做、怎么做、发现了什么、意味着什么”的逻辑链条。
3. **大纲细化**：为每个章节生成详细的段落要点。

## 工作流
- **Step 1**: 确定核心科学问题（Hypothesis）。
- **Step 2**: 选择模板（[references/templates.md](references/templates.md)）。
- **Step 3**: 填充核心论点，构建逻辑流。
- **Step 4**: 评审大纲的严密性。

## 技巧
- **IMRaD**: Introduction -> Methods -> Results -> Discussion.
- **NSFC**: 立项依据 -> 研究目标 -> 研究内容 -> 关键科学问题 -> 技术路线。

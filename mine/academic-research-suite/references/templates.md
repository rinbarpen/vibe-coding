# 逻辑架构模板

## 1. 论文 IMRaD 模板
- **Introduction**: 背景 -> Gap -> 本研究目标。
- **Methods**: 实验设计 -> 数据采集 -> 分析方法。
- **Results**: 核心发现 1 -> 核心发现 2 -> 核心发现 3。
- **Discussion**: 结果解释 -> 与前人对比 -> 局限性与未来方向。

## 2. NSFC 基金模板
- **立项依据**: 科学意义 -> 国内外现状 -> 存在问题 -> 本项目切入点。
- **研究内容**: 模块化描述具体要做的 3-4 件事。
- **关键科学问题**: 提炼 1-2 个本质矛盾。
- **技术路线**: 逻辑流程图的文字描述。

## 3. Storyline 检查
- 每一段的第一句话是否能连成一个完整的故事？
- 所有的结果是否都直接支持了你的假设？

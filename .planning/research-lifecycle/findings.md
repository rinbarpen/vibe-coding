# Findings
Existing scaffold has Writing Plan; no lifecycle runtime. Public CLI unchanged.
Native model IDs are deployment-specific: store requested profiles and explicit bindings; no invented model availability.
Use standard-library helpers and isolated Git repositories for tests; no paid model or cloud invocations.

Table purpose, structure and style are distinct. Reference-label bolding does not imply significance. Coloured review preview is separate from monochrome Word delivery.

Substage output contracts are handoff records and may reference existing scientific artifacts. Completion checks validate file/hash and reviewer attestations, not scientific truth or human identity. Defaults enforce the new gate, existing settings need explicit migration.

Table Plan uses explicit experiment/configuration/protocol/source-kind/seed selection to avoid ambiguous pooling. Review checks current raw output and generated source hashes, not scientific truth or upstream audit identity.

Paired ablations need covariance preserved: calculate the contrast per seed first,
then aggregate; marginal SDs do not determine contrast SD. Interaction signs alone
establish neither synergy nor significance. Current design checks only declared
controls; scientific fairness and real venue layout remain separate review tasks.

Composition ownership must not inherit, unlike style: inheriting asset lists into
paragraphs duplicates layout responsibility. Writer packets expose planned sibling
summaries, not invented completed text. Asset references and literal labels are
source-level checks only; missing include expansion, first-use order and rendered
page observations stay explicit. Warning exit 0 is not final publication approval.

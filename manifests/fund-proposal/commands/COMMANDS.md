# 基金本子专用执行指令清单 (Fund_Craft_Pro Commands)

本清单定义了 `Fund_Craft_Pro` 专家的核心执行指令。AI 助手应严格按照指令定义的逻辑与关联的 Skills 执行任务。

| 指令 | 描述 | 执行逻辑 | 建议调用的 Skills |
| :--- | :--- | :--- | :--- |
| `/init` | 启动向导 | 询问学科代码、研究方向、前期数据和最终目标。 | `fund-research` |
| `/brainstorm` | 选题与 Gap 分析 | 使用“5W1H”和“矛盾分析法”找出研究领域的 Gap。 | `fund-research` |
| `/outline` | 构建逻辑闭环大纲 | 输出标准基金大纲，明确“漏斗结构”，区分内容、目标与方法。 | `writing-plans`, `fund-visuals` |
| `/draft [章节]` | 章节撰写 | 1. 列段落大意；2. 输出学术文本；3. 预留图表占位符。 | `fund-writing`, `fund-visuals` |
| `/polish [文本]` | 学术润色 | 保留原意，提高信息密度，优化逻辑连词（因此、然而、旨在）。 | `fund-writing` |
| `/review` | 毒舌评审 | 从创新性、科学价值、可行性、逻辑自洽性四个维度打分并给出 Reject 理由。 | `fund-review` |

## 指令执行规范

### 1. `/init` (初始化)
- **目标**: 建立项目基准。
- **动作**: 盘问用户研究基础，禁止直接生成大段文本。

### 2. `/brainstorm` (头脑风暴)
- **目标**: 提炼【关键科学问题】和【创新点】。
- **动作**: 识别现有研究的局限性（Gap），确保科学问题具有挑战性。

### 3. `/outline` (架构设计)
- **目标**: 确保逻辑闭环。
- **动作**: 明确立项依据的“漏斗”逻辑：大背景 -> 小领域 -> 核心问题 -> 本研究切入点。

### 4. `/draft` (正文撰写)
- **目标**: 高质量学术产出。
- **动作**: 严禁捏造数据，必须使用占位符 `[请补充...]`。

### 5. `/polish` (润色优化)
- **目标**: 提升信息密度。
- **动作**: 遵循 `chinese-copywriting-guidelines` 处理中英空格，使用 `beautiful_prose` 增强语势。

### 6. `/review` (模拟评审)
- **目标**: 逻辑挑刺。
- **动作**: 模拟“大同行”视角看意义，“小同行”视角看方案。给出具体的修改方案，而非空洞赞美。

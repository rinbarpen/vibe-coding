# Contributing to UI Testing Manifest

## Development Workflow

1. Fork the repository.
2. Create a feature branch.
3. Make changes to rules, commands, patterns, or scenarios.
4. Verify structure: ensure all `.mdc` files have valid YAML frontmatter.
5. Test initialization: run `ui-testing-init.sh` against a test project.
6. Submit a PR with a summary of the changes and a test plan.

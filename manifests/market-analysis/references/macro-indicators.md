# 宏观指标手册

## 国内核心宏观指标

### 经济增长
| 指标 | 发布频率 | 发布单位 | 说明 |
|------|:--------:|---------|------|
| **GDP** (国内生产总值) | 季度 | 统计局 | 经济总量，同比增速为关注核心 |
| **工业增加值** | 月度 | 统计局 | 工业生产活跃度 |
| **社会消费品零售总额** | 月度 | 统计局 | 消费活力 |
| **固定资产投资** | 月度 | 统计局 | 基建/制造业/房地产投资 |

### 物价
| 指标 | 发布频率 | 说明 |
|------|:--------:|------|
| **CPI** (居民消费价格) | 月度 | 通胀指标，>3% 警惕通胀，<0% 警惕通缩 |
| **PPI** (工业生产者出厂价格) | 月度 | 上游价格，领先 CPI |
| **核心CPI** (剔除食品能源) | 月度 | 更准确反映通胀趋势 |

### 货币与流动性
| 指标 | 说明 |
|------|------|
| **M2** (广义货币供应量) | 货币宽松程度，>10% 宽松，<8% 紧缩 |
| **社融规模** | 实体经济融资需求 |
| **LPR** (贷款市场报价利率) | 基准利率，1年期/5年期 |
| **MLF** (中期借贷便利) | 政策利率指向标 |
| **10年期国债收益率** | 市场利率锚，债券市场风向标 |

### 房地产
| 指标 | 说明 |
|------|------|
| **商品房销售面积** | 需求端 |
| **房地产开发投资** | 供给端 |
| **70城房价指数** | 价格端 |

## 国际宏观指标

| 指标 | 发布方 | 说明 |
|------|--------|------|
| **美国非农就业** | BLS (劳工统计局) | 每月第一个周五，全球最重要宏观数据 |
| **美国CPI** | BLS | 全球通胀风向标 |
| **美联储利率决议** | FOMC | 每6周一次，影响全球资金流向 |
| **PMI** (制造业/服务业) | ISM/S&P Global | 经济先行指标，>50扩张，<50收缩 |
| **消费者信心指数** | 密歇根大学 | 消费预期 |

## 宏观分析框架

### 美林时钟 (Merrill Lynch Clock)

| 阶段 | GDP | CPI | 最佳资产 |
|:----:|:---:|:---:|---------|
| 复苏 | ↑ | ↓ | 股票 |
| 过热 | ↑ | ↑ | 商品 |
| 滞胀 | ↓ | ↑ | 现金/黄金 |
| 衰退 | ↓ | ↓ | 债券 |

### 信用-货币四象限

| 货币/信用 | 宽松 | 紧缩 |
|-----------|:----:|:----:|
| **宽货币+宽信用** | 📈 股票/商品 | — |
| **宽货币+紧信用** | 📈 债券 | — |
| **紧货币+宽信用** | — | 📉 债券 |
| **紧货币+紧信用** | — | 📉 股票 |

### 利率敏感度排序

```
地产 ≈ 家电 > 汽车 ≈ 券商 > 银行 > 消费 > 医药 > 公用事业
(利率下降利好的行业顺序)
```

## 数据注意事项

- 宏观数据通常有 **1-3 个月的发布滞后**
- 初值经常被修正，以终值为准
- 中国市场数据受春节因素影响，1-2月数据需合并看待
- 同比 vs 环比：同比消除季节性，环比更敏感
- 基数效应：低基数导致同比高增不一定是真改善

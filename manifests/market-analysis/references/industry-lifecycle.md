# 行业生命周期分析指南

## 四阶段模型

```
市场/营收
   ↑                 成熟期
   │                 ┌─────
   │            ┌────┤ 增长率放缓
   │     成长期 │    │ 格局稳定
   │     ┌──────┤    │ 利润最高
   │     │高增长│    └─────
   │     │竞争  │           └─────── 衰退期
   │     │加剧  │                   ↑ 市场萎缩
   │导入期│     │                   │ 产能过剩
   │┌────┤     │                   │ 退出增加
   ││低  │     │                   │
   ││增长│     │                   │
   ││高  │     │                   │
   ││风险│     │                   │
   └┴───┴─────┴─────────────────┴──────→ 时间
```

## 各阶段特征

### 导入期 (Introduction)

| 维度 | 特征 |
|------|------|
| **市场增长率** | 低（产品认知度低） |
| **竞争格局** | 少数先行者，探索商业模式 |
| **技术** | 技术路线不确定，迭代快 |
| **客户** | 创新者 (Innovators) |
| **利润** | 负或极低（投入大） |
| **现金** | 消耗大，需要融资 |
| **风险** | 技术失败、市场不认可 |
| **典型行业** | 早期AI应用、量子计算 |

### 成长期 (Growth)

| 维度 | 特征 |
|------|------|
| **市场增长率** | 高（20%+） |
| **竞争格局** | 参与者激增，跑马圈地 |
| **技术** | 主流技术方案逐渐明确 |
| **客户** | 早期多数 (Early Majority) |
| **利润** | 改善但可能仍为负（再投资） |
| **现金** | 仍需要融资扩张 |
| **风险** | 竞争加剧、产能过剩 |
| **典型行业** | 新能源车、云计算 |

### 成熟期 (Maturity)

| 维度 | 特征 |
|------|------|
| **市场增长率** | 低（<5% 或跟随GDP） |
| **竞争格局** | 集中化、整合、寡头 |
| **技术** | 标准化，差异缩小 |
| **客户** | 后发多数 (Late Majority) |
| **利润** | 最高峰（规模效应） |
| **现金** | 现金牛 |
| **风险** | 颠覆性技术替代 |
| **典型行业** | 汽车、家电、银行 |

### 衰退期 (Decline)

| 维度 | 特征 |
|------|------|
| **市场增长率** | 负 |
| **竞争格局** | 退出增加，少量寡头 |
| **技术** | 被新技术替代 |
| **客户** | 落后者 (Laggards) |
| **利润** | 下降，价格竞争 |
| **现金** | 收割 (Harvest) |
| **风险** | 行业消亡 |
| **典型行业** | 纸质媒体、固话 |

## 生命周期位置判断

### 关键问题清单

| 问题 | 导入期 | 成长期 | 成熟期 | 衰退期 |
|------|:----:|:------:|:------:|:------:|
| 市场增速 > 10%? | ❌ | ✅ | ❌ | ❌ |
| 参与者数量增加? | 缓慢 | 快速 | 减少 | 减少 |
| 技术路线确定? | ❌ | 逐渐 | ✅ | ✅ |
| 盈利企业占比? | 低 | 中等 | 高 | 下降 |
| 投资需求大? | ✅ | ✅ | ❌ | ❌ |

### 帕特生命曲线 (Porter's Life Cycle)

```
            导入期         成长期         成熟期         衰退期
进入壁垒    ↑上升         ↑高           ↑高           ↓下降
供应商力    ↑上升         →中           ↓下降         ↓很低
买方力      ↑上升         →中           ↑上升         ↑高
替代品      ↑上升         →中           →中           ↑高
竞争程度    →低           ↑高           →中           ↓低
```

## 策略启示

| 阶段 | 建议策略 |
|:----:|---------|
| **导入期** | 快速试错、建立技术壁垒、获取早期用户 |
| **成长期** | 抢占市场份额、品牌建设、规模扩张 |
| **成熟期** | 成本领先/差异化、效率优化、现金回报 |
| **衰退期** | 收割策略、收缩、寻找新增长点 |

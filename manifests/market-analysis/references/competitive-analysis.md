# 竞争格局分析方法

## 分析框架

```
宏观行业 → 识别玩家 → 分类定位 → 份额估算 → 深度对比 → 动态趋势
   ↓           ↓          ↓           ↓          ↓          ↓
 行业定义   主要公司  领导者/挑战  营收份额   产品/渠道  合并收购
 细分领域   新进入者  者/利基   用户份额   技术/品牌  进入退出
            替代者   者/尾随   产能份额   成本/利润  市场份额变化
```

## 1. 竞争者识别

### 分类维度

| 维度 | 说明 |
|------|------|
| **直接竞争者** | 相同产品/服务，相同市场 |
| **间接竞争者** | 不同产品/服务，满足相同需求 |
| **潜在竞争者** | 可能从相邻市场进入的企业 |
| **替代者** | 用完全不同的方式满足需求 |

### 竞争层级

```markdown
以"咖啡店"行业为例:
- 直接竞争: 星巴克 vs 瑞幸（同品类）
- 间接竞争: 便利店咖啡、速溶咖啡（同需求）
- 潜在竞争: 茶饮品牌进军咖啡（相邻市场）
- 替代: 功能饮料、茶（不同方式提神）
```

## 2. 战略群组分析 (Strategic Group Mapping)

将行业内企业按**战略维度**分组，识别不同竞争定位。

### 绘制步骤

1. 选择两个关键战略维度（如价格×品质、广度×垂直度）
2. 将企业定位到二维矩阵
3. 圈出战略相似的群组
4. 分析各群组间的移动壁垒

### 示例：新能源汽车

```
价格↑
 高  │ 特斯拉 │
     │ 蔚来   │
 中  │ 比亚迪 │ 小米
     │ 大众   │
 低  │ 五菱   │
     └─────────→ 产品线宽度
      窄      宽
```

## 3. 市场份额估算

### 数据来源

| 来源 | 适用 | 可信度 |
|------|------|:------:|
| 上市公司年报 | 上市公司 | ⭐⭐⭐⭐⭐ |
| 行业协会数据 | 全行业 | ⭐⭐⭐⭐ |
| 第三方报告 (IDC/Gartner) | 科技行业 | ⭐⭐⭐⭐ |
| 营收推算（招聘/产能） | 非上市公司 | ⭐⭐ |
| 用户调研 | 消费行业 | ⭐⭐⭐ |

### 估算技巧（当数据不可得时）

```
某公司市场份额 ≈ 该公司营收 / 行业总营收

行业总营收 ≈ 从业公司数 × 平均公司营收
           ≈ 用户数 × 平均客单价
           ≈ 产能 × 产能利用率 × 平均售价

招聘法: 员工数 × 人均营收 = 公司营收估算
```

## 4. 集中度指标

### CR3 / CR5 (Concentration Ratio)

```
CR3 = 前3大企业市场份额之和
CR5 = 前5大企业市场份额之和

CR3 > 70%  → 高度集中（寡头）
CR3 40-70% → 中度集中
CR3 < 40%  → 分散市场
```

### HHI (Herfindahl-Hirschman Index)

```
HHI = Σ(各企业市场份额%)²

HHI > 2500 → 高度集中
HHI 1500-2500 → 中度集中
HHI < 1500 → 分散市场
```

## 5. 竞争分析工具

### SWOT 分析

| 维度 | 内部分析 | 外部分析 |
|:----:|---------|---------|
| **正向** | S (优势) | O (机会) |
| **负向** | W (劣势) | T (威胁) |

### 竞争对手雷达图

```
          产品力
            5
         ┌──┼──┐
品牌力  4─┤  │  │─4 渠道力
         │  │  │
         └──┼──┘
          3 └── 技术力
         成本力
```
（在蜘蛛图上比较企业与主要竞争对手）

### BCG 矩阵

| 市场增长率 | 明星 (Stars) | 问题 (Question Marks) |
|:----------:|:------------:|:--------------------:|
| **高** | 高增长+高份额 → 投资 | 高增长+低份额 → 选择或放弃 |
| **低** | 现金牛 (Cash Cows) | 瘦狗 (Dogs) |
| | 低增长+高份额 → 收割 | 低增长+低份额 → 退出 |
| | **高** ← 相对市场份额 → **低** |

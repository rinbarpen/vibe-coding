# 行业研究方法参考

## 行业分类标准

| 标准 | 粒度 | 适用范围 |
|------|:----:|---------|
| **申万行业分类** | 一级31个/二级134个 | A股最常用 |
| **中信行业分类** | 一级30个/二级120个 | 机构研究常用 |
| **GICS** (全球行业分类) | 一级11个/二级24个 | 国际对标 |
| **证监会行业分类** | 一级19个 | 官方统计 |

## 行业研究框架

### 1. 行业生命周期

```
导入期 → 成长期 → 成熟期 → 衰退期
  ↓        ↓        ↓        ↓
高风险    高增长    稳定    收缩
高投入    估值高    分红    现金牛
```

### 2. 波特五力分析

| 力量 | 说明 |
|------|------|
| **供应商议价能力** | 上游集中度、替代成本 |
| **买方议价能力** | 下游集中度、转换成本 |
| **新进入者威胁** | 门槛、牌照、技术壁垒 |
| **替代品威胁** | 跨行业替代、技术革命 |
| **同业竞争** | 竞争格局、市场集中度 (CR5/HHI) |

### 3. 行业关键指标

| 行业类型 | 核心指标 |
|----------|----------|
| 消费 | 同店增长、客单价、复购率 |
| 科技 | ARPU、用户数、研发投入占比 |
| 制造 | 产能利用率、毛利率、设备开工率 |
| 金融 | NIM（净息差）、不良率、资本充足率 |
| 医药 | 管线进度、专利期、渗透率 |
| 地产 | 去化周期、拿地成本、融资成本 |

## 行业轮动策略

### 经济周期与行业表现

| 阶段 | 领先行业 |
|:----:|---------|
| 复苏初期 | 金融、可选消费 |
| 繁荣期 | 科技、工业 |
| 过热期 | 能源、材料 |
| 衰退期 | 公用事业、医药、必选消费 |

### 利率敏感行业

| 利率方向 | 受益行业 |
|:--------:|---------|
| 降息 | 地产、券商、保险 |
| 升息 | 银行、保险 |

## 行业比较维度

```
成长性（营收增速） → 哪些行业在加速？
盈利能力（ROE）  → 哪些行业最赚钱？
估值水平（PE/PB） → 哪些行业被低估？
机构持仓（基金重仓） → 聪明钱在买什么？
北向资金（外资）  → 海外资金配置方向？
```

## 数据获取

- **行业指数**: AkShare `stock_board_industry_hist_em`
- **行业成分股**: AkShare `stock_board_industry_cons_em`
- **行业财务**: 通过个股财报汇总
- **上下游数据**: 宏观指标中的行业相关数据（如水泥产量→基建行业）

# 个股深度分析框架

## 分析框架总览

```
┌─────────────────────────────────────────────────────────┐
│                    第一层：商业模型                       │
│  怎么赚钱？→ 赚多少钱？→ 赚钱难不难？→ 能赚多久？      │
└──────────────────────────┬──────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────┐
│                    第二层：竞争壁垒                       │
│  护城河多宽？→ 竞争对手能复制吗？→ 客户粘性多强？      │

                           ↓
┌─────────────────────────────────────────────────────────┐
│                    第三层：财务健康                       │

                           ↓
┌─────────────────────────────────────────────────────────┐
│                    第四层：管理层与治理                   │
```

## 第一层：商业模型分析

### 六个核心问题

| 问题 | 判断维度 | 好信号 | 坏信号 |
|:----:|---------|--------|--------|
| **卖什么？** | 产品/服务形态 | 高复购性产品 | 一次性项目 |
| **卖给谁？** | 客户类型与集中度 | 分散、多元化 | 依赖大客户 |
| **怎么收费？** | 定价模式 | 订阅/按用量 | 项目制/关系单 |
| **成本结构？** | 固定 vs 可变 | 高毛利、轻资产 | 低毛利、重资产 |
| **增长驱动力？** | 量价拆分 | 量价齐升 | 仅靠涨价 |
| **规模效应？** | 边际成本曲线 | 越做越赚钱 | 规模不经济 |

### 商业模型分类

| 模型 | 特点 | 典型公司 | 分析重点 |
|:----:|------|---------|---------|
| **SaaS** | 订阅制、高毛利、高粘性 | 金山办公 | ARR、NDR、Churn |
| **平台** | 双边网络效应 | 美团、阿里 | GMV、Take rate |
| **产品** | 标准化产品 | 海康威视 | ASP、出货量 |
| **项目** | 定制化交付 | 中软国际 | 人效、复购率 |
| **交易** | 佣金/抽成 | 贝壳 | 市占率、货币化率 |
| **硬件+软件** | 硬件入口+软件增值 | 小米 | 用户ARPU、配件率 |

## 第二层：竞争壁垒分析

### 六种护城河

| 类型 | 判断方法 | 来自行业研究的证据 |
|:----:|---------|------------------|
| **🏷️ 品牌** | 用户是否愿意为品牌付溢价？ | 行业品牌集中度、用户调研 |
| **🔄 转换成本** | 客户迁移到竞品的代价多大？ | 产业链分析中的下游粘性 |
| **🌐 网络效应** | 用户越多产品越好用？ | 竞争对手数量、用户增长曲线 |
| **💰 成本优势** | 能以低于对手的成本提供同等产品？ | 价值链分析中的成本结构 |
| **🔬 专利/技术** | 技术能否被复制？ | 技术评估中的TRL和专利分析 |
| **📜 牌照/许可** | 政策是否保护了在位者？ | 政策分析中的准入壁垒 |

### 护城河评分

```markdown
| 护城河类型 | 评分(1-5) | 证据 |
|-----------|:---------:|------|
| 转换成本 | 4 | 企业部署AI后迁移成本高 |
| 技术/专利 | 3 | LLM技术仍在快速演进，壁垒不持久 |
| 品牌 | 3 | 有一定品牌但非决策核心 |
| 网络效应 | 2 | 平台效应不明显 |
| 成本优势 | 2 | 云服务商之间价格竞争激烈 |
| 综合 | ⭐⭐⭐ | 中等护城河，主要靠转换成本 |
```

## 第三层：财务分析

### 收入质量

| 指标 | 公式 | 好信号 | 坏信号 |
|------|------|--------|--------|
| **收入增速** | (当期-上期)/上期 | >行业增速 | <行业增速 |
| **经常性收入占比** | 订阅/维护/服务 / 总收入 | >60% | <30% |
| **客户集中度** | 前5大客户占比 | <20% | >50% |
| **NDR (净留存率)** | (期初收入-流失+扩张)/期初 | >120% | <100% |
| **合同负债** | 已收未确认收入 | 增长 | 下降 |

### 盈利效率

| 指标 | 公式 | 好信号 |
|------|------|--------|
| **毛利率** | (收入-直接成本)/收入 | >60%（软件），>30%（硬件） |
| **营业利润率** | 营业利润/收入 | >15% |
| **ROIC (投入资本回报率)** | NOPAT/投入资本 | >15%且>WACC |
| **研发费用率** | 研发费用/收入 | 高但可解释（成长期） |

### 现金流

| 指标 | 含义 | 好信号 |
|------|------|--------|
| **FCF (自由现金流)** | 经营性现金流-资本支出 | 正且增长 |
| **FCF转化率** | FCF/净利润 | >80% |
| **运营资本效率** | 应收账款+存货-应付账款 | 负（占用别人资金） |

### 财务健康检查清单

```
□ 收入增速是否超过行业增速？
□ 毛利率是否稳定或提升？
□ ROIC > WACC → 公司在创造价值
□ FCF为正，或路径清晰（成长期可理解FCF为负）
□ 公司是否依赖融资生存？（烧钱率？现金跑道？）
□ 应收账款增速 & 收入增速（是否在放松收款条件？）
□ 商誉/无形资产占比（收购带来的风险）
□ 股权激励稀释率（每年稀释多少？）
```

## 第四层：管理层与治理

### 评估维度

```markdown
## 管理层评估

| 维度 | 问题 | 好信号 |
|------|------|--------|
| 背景 | 创始人/CEO是否有行业经验？ | 行业深耕10年+ |
| 资本配置 | 历史并购和投资回报如何？ | 投资回报>资金成本 |
| 激励 | 管理层薪酬和股东利益绑定？ | 大量持股，无短期业绩考核 |
| 沟通 | 对投资者的透明度？ | 坦诚面对挑战 |
| 团队 | 核心团队稳定性？ | 高管离职率低 |

## 治理评估

| 维度 | 好信号 | 坏信号 |
|------|--------|--------|
| 股权结构 | 有控股股东但非一股独大 | 创始人一股独大，无制衡 |
| 董事会 | 独立董事占多数，有行业专家 | 全部内部人 |
| 关联交易 | 披露充分，定价公允 | 大量不透明的关联交易 |
| 分红政策 | 稳定分红或明确回购计划 | 随意变更分红政策 |
```

## 第五层：估值分析

### 常用估值方法

| 方法 | 适用 | 原理 |
|:----:|:----:|------|
| **PE (市盈率)** | 盈利稳定的公司 | 市值/净利润 |
| **PS (市销率)** | 亏损/高增长公司 | 市值/收入 |
| **EV/EBITDA** | 资本密集行业 | 企业价值/税息折旧前利润 |
| **DCF (现金流折现)** | 有稳定现金流预测 | 未来FCF折现到今天 |
| **可比公司分析** | 有同类上市公司 | 同行估值倍数对比 |

### 估值区间判断

```markdown
## 示例：AI软件公司估值框架

估值方法1: PS估值
  ┌─────────────┬──────────┬──────────┐
  │ 公司        │ PS(TTM)  │ PS(NTM)  │
  ├─────────────┼──────────┼──────────┤
  │ 金山办公    │ 25x      │ 20x      │
  │ 科大讯飞    │ 8x       │ 6x       │
  │ 恒生电子    │ 10x      │ 8x       │
  │ 行业平均    │ 12x      │ 10x      │
  └─────────────┴──────────┴──────────┘

估值方法2: PEG (PE/增长率)
  - 行业平均PEG ≈ 1.5x
  - 高增长公司享受溢价（PEG > 2）
  - 低增长公司可能折价（PEG < 1）

估值方法3: DCF敏感性分析
           │  WACC
           │  9%   10%   11%
  ─────────┼─────────────────
  终值增长  │
    2%     │ 120   100   85
    3%     │ 150   120   100
    4%     │ 200   150   120
  
  DCF估值区间: 85-200元/股（取决于假设）
```

### 估值注意事项

- **看相对也看绝对**：PE高不一定贵，要看增速（PEG）
- **和谁比**：同一行业、相似商业模式的公司
- **市场在price in什么**：当前估值隐含了什么增长率预期？这个预期合理吗？
- **安全边际**：你的分析和市场的共识有什么分歧？

## 个股分析检查清单（完整版）

```
□ 商业模型理解
  □ 能用一句话说清楚这家公司怎么赚钱
  □ 收入是经常性还是项目性的？
  □ 客户是谁？集中度多高？
  □ 规模效应存在吗？

□ 竞争壁垒
  □ 护城河是什么类型？
  □ 行业研究中的竞争格局如何影响这家公司？
  □ 竞争对手能复制吗？

□ 财务分析
  □ 收入增速和质量
  □ 毛利率趋势
  □ ROIC vs WACC
  □ FCF健康度
  □ 资产负债表风险

□ 管理层
  □ 管理层质量
  □ 激励结构
  □ 资本配置历史

□ 估值
  □ 当前估值隐含了什么预期？
  □ 与历史和同行比是贵还是便宜？
  □ 有安全边际吗？

□ 投资假设整合
  □ 行业研究中的关键变量如何影响这家公司？
  □ 这个公司在行业中的定位是什么？
  □ 综合判断：机会大于风险？还是反之？
```

# 投资假设框架：从行业研究到投资假设

## 核心原则

行业研究回答"行业怎么样"→ 投资假设回答"基于这个行业的洞察，什么样的投资逻辑可能成立"。

**不是推荐，而是逻辑推演。** 
每一条假设都是可验证的（如果……那么……），而不是模糊的方向判断。

---

## 投资假设的四种基本类型

| 类型 | 逻辑 | 行业研究提供的依据 |
|:----:|------|------------------|
| **结构性增长** | 行业长期增长驱动因素不变，龙头企业将持续受益 | 市场规模、CAGR、渗透率 |
| **格局优化** | 行业集中度提升，龙头吃份额 | 竞争格局、CR3/CR5趋势、进入壁垒 |
| **拐点/周期** | 行业处于周期底部或技术转折点 | 技术成熟度、政策方向、库存周期 |
| **颠覆/价值重估** | 现有格局被打破，新玩家/新模式崛起 | 颠覆性技术、政策变化、产业链重构 |

## 五步推导法

### Step 1: 识别行业关键变量

从行业研究中提取最核心的 3-5 个变量：

```markdown
以AI软件行业为例:
关键变量1: 推理成本下降速度 → 决定应用层爆发的临界点
关键变量2: 企业AI采用率 → 决定市场需求增速
关键变量3: 开源模型 vs 闭源模型竞争 → 决定价值链利润分布
关键变量4: GPU供给约束 → 决定算力成本
关键变量5: AI监管政策走向 → 决定合规成本和市场规模
```

### Step 2: 推演各变量的影响方向

```
关键变量 → 正面影响谁？ → 负面影响谁？ → 影响多大？ → 概率多高？

例：推理成本下降90%+
  ├→ 正面: AI应用层公司（成本下降→需求爆发→收入增长）
  ├→ 正面: 中小企业（以前用不起AI，现在用得起）
  ├→ 负面: GPU云服务商（推理需求单价下降）
  └→ 中性: LLM基础模型公司（量升价跌，看弹性）
```

### Step 3: 形成可验证假设

每条假设必须有明确的**判断标准**和**验证时间**：

```markdown
✅ 好的假设:
"如果推理成本持续下降，AI应用层公司的收入增速将超过模型层公司"
- 验证: 2026年报中，应用层公司AI收入占比提升
- 数据来源: 各公司财报
- 时间窗口: 2026-2027

❌ 差的假设:
"AI行业前景很好"（无法验证，没有判断标准）

✅ 好的假设:
"如果企业AI采用率突破60%，AI SaaS公司的ARR将加速增长"
- 验证: 头部AI SaaS公司季度财报ARR增速
- 数据来源: 公司财报、投资者演示
- 时间窗口: 2026H2-2027H1
```

### Step 4: 识别反方观点（压力测试）

每条假设至少要有一个强有力的反方观点：

```markdown
假设: "推理成本下降利好AI应用层"
反方: "推理成本下降也降低了竞争对手的进入门槛，导致价格战"
化解办法: 寻找有数据壁垒+用户粘性的应用层公司
```

### Step 5: 设定跟踪触发点

```markdown
| 关键信号 | 验证什么 | 如果发生则 |
|----------|---------|-----------|
| 某龙头公司AI收入占比超30% | 商业化落地验证 | 假设得到支撑 |
| 开源模型在关键基准上超越闭源 | 技术格局变化 | 重新评估模型层投资逻辑 |
| GPU出口管制进一步升级 | 算力供给收缩 | 利好国产替代，利空AI整体 |
```

## 从行业研究到投资假设：AI软件案例

### 行业研究发现

| 发现 | 数据 |
|------|------|
| AI软件市场378亿，CAGR 39% | IDC, 2025 |
| 推理成本下降90%+ | 行业定价数据 |
| 企业AI采用率52%，但深度整合仅18% | McKinsey, 2025 |
| CR3=55%，百度22%/阿里18%/腾讯15% | IDC, 2025 |
| LLM层面临开源商品化压力 | 行业分析 |

### 推导出的投资假设

```markdown
假设1: 应用层赢家
  "企业AI采用率从52%→80%的过程中， 
  拥有行业数据壁垒的AI应用公司最受益"
  支撑: 深度整合率仅18%→提升空间大；数据壁垒阻止开源竞争
  反方: 应用层竞争激烈，变现速度可能慢于预期
  跟踪: 应用公司AI订阅收入增速 vs 行业平均

假设2: 产业链价值迁移
  "推理成本下降90%+，利润从基础设施层向应用层迁移"
  支撑: 成本下降→应用需求爆发→应用定价权更强
  反方: 基础设施层也受益于量增（Jevons悖论）
  跟踪: 各环节上市公司毛利率变化趋势

假设3: 国产替代逻辑
  "GPU出口管制持续，国产AI芯片产业链受益"
  支撑: 华为昇腾性能提升，政策支持国产替代
  反方: 国产芯片性能和生态差距仍然显著
  跟踪: 国产AI芯片出货量、大厂采购占比

假设4: 行业整合逻辑
  "融资环境收缩+竞争加剧→行业集中度提升，
  头部平台公司受益"
  支撑: 2025年AI创业融资降温，烧钱模式不可持续
  反方: 大厂自身也在亏损，整合动力不足
  跟踪: 行业并购事件、创业公司退出情况
```

## 投资假设检查清单

```
□ 假设是"如果…那么…"的形式吗？
□ 有明确的判断标准吗？
□ 有时间窗口吗？（什么时候验证？）
□ 数据来源是什么？
□ 有反方观点吗？什么时候假设会错？
□ 跟踪触发点设了吗？
□ 这个假设和行业研究的核心冲突矛盾吗？
□ 推导过程有跳步吗？（行业A→利好B，中间的因果链完整吗？）
```

## 常见错误

- ❌ **假设太模糊**：不能验证的假设没有价值
- ❌ **跳过竞争分析**：只看行业增长，不看谁吃到增长
- ❌ **线性外推**：过去涨了50%→明年还会涨50%
- ❌ **忽视概率**：只说可能发生，不说发生概率多大
- ❌ **确认偏误**：只找支持假设的证据，不看反方观点

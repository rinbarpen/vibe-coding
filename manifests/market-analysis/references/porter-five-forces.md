# 波特五力分析指南

## 概述

哈佛商学院教授迈克尔·波特 (Michael Porter) 于1979年提出的行业竞争分析框架。五力决定一个行业的**长期盈利潜力**。

## 五力模型

```
                    ┌──────────────────┐
                    │  新进入者威胁    │
                    │  (Threat of      │
                    │   New Entrants)  │
                    └────────┬─────────┘
                             │
    ┌───────────┐    ┌──────┴──────┐    ┌───────────┐
    │ 供应商     │    │              │    │ 买方       │
    │ 议价能力   │◄──┤  同业竞争    ├──►│ 议价能力   │
    │ (Supplier  │    │ (Rivalry     │    │ (Buyer     │
    │  Power)   │    │  Among       │    │  Power)   │
    └───────────┘    │  Existing    │    └───────────┘
                     │  Firms)     │
                     └──────┬──────┘
                             │
                    ┌────────┴─────────┐
                    │  替代品威胁       │
                    │  (Threat of      │
                    │   Substitutes)   │
                    └──────────────────┘
```

## 分力分析指南

### 1. 同业竞争 (Rivalry)

**考察指标**:
- 行业集中度 (CR3、CR5、HHI)
- 行业增长率（高增长→竞争缓和，低增长→竞争激烈）
- 产品差异化程度
- 退出壁垒高低
- 固定成本/可变成本比例

**信号判断**:
| 信号 | 竞争激烈 | 竞争缓和 |
|------|---------|---------|
| 价格战 | 频繁 | 少见 |
| 广告投入 | 高 | 适中 |
| 新产品推出 | 快 | 稳定 |
| 行业利润率 | 低于平均 | 高于平均 |

### 2. 新进入者威胁

**进入壁垒类型**:
| 壁垒类型 | 说明 | 示例 |
|----------|------|------|
| 规模经济 | 现有企业成本优势 | 芯片制造、航空 |
| 品牌忠诚度 | 消费者信任 | 可乐、奢侈品 |
| 资本要求 | 启动资金门槛 | 汽车、制药 |
| 转换成本 | 用户切换成本 | 企业软件、云计算 |
| 渠道准入 | 销售渠道控制 | 快消品 |
| 政策壁垒 | 牌照/许可 | 金融、电信 |
| 网络效应 | 用户越多越有价值 | 社交平台、电商 |

### 3. 替代品威胁

**评估维度**:
- 替代品的性价比（价格/性能比）
- 用户的转换意愿和成本
- 替代品所在行业的利润率（高利润→替代者更有动力）

### 4. 供应商议价能力

**强议价能力的信号**:
- 供应商集中度高于买方
- 供应商产品差异化高或无替代品
- 供应商产品是买方业务的关键投入
- 供应商有向前整合的威胁
- 转换成本高

### 5. 买方议价能力

**强议价能力的信号**:
- 买方集中度高（少数大客户）
- 买方采购量大
- 产品标准化（无差异）
- 买方转换成本低
- 买方有向后整合的威胁
- 产品占买方成本的比例高

## 五力评分的应用

```markdown
| 力量 | 评分(1-5) | 说明 |
|------|:---------:|------|
| 同业竞争 | 4 | 增长放缓，价格战频繁 |
| 新进入者 | 2 | 技术壁垒高，资本要求大 |
| 替代品 | 3 | 有替代方案但性能不足 |
| 供应商 | 2 | 上游竞争充分，供给充足 |
| 买方 | 4 | 大客户议价能力强 |
| **行业吸引力** | **中偏低** | 竞争激烈+买方强势挤压利润 |
```

| 总分 | 行业判断 |
|:----:|---------|
| 5-10 | 高吸引力，利润丰厚 |
| 10-15 | 中等吸引力 |
| 15-20 | 低吸引力，利润受压 |
| 20-25 | 极低吸引力，可能需要退出 |

## 常见误区

- ❌ **把五力当静态分析** — 五力会随时间变化
- ❌ **忽视第六力** — 有些学者建议加入"互补品"或"政府"作为第六力
- ❌ **只看竞争不看合作** — 行业内的联盟和合作关系也很重要
- ❌ **忽略行业边界变化** — 技术融合导致行业边界模糊（如手机=相机+导航+通信）

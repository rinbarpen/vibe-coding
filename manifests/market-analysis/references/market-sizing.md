# 市场规模估算指南

## 核心概念

### TAM / SAM / SOM

```
          ┌────────────────────┐
          │   TAM (总可用市场)  │
          │  全品类全球市场总额 │
          │ ┌──────────────┐   │
          │ │ SAM (可服务市场)│  │
          │ │ 产品和渠道可   │   │
          │ │ 覆盖的市场     │   │
          │ │ ┌──────────┐  │   │
          │ │ │SOM(可获) │  │   │
          │ │ │ 实际可   │  │   │
          │ │ │ 获取份额 │  │   │
          │ │ └──────────┘  │   │
          │ └──────────────┘   │
          └────────────────────┘
```

| 概念 | 说明 | 用途 |
|------|------|------|
| **TAM** (Total Addressable Market) | 品类的全球/全市场总需求 | 行业天花板判断 |
| **SAM** (Serviceable Addressable Market) | TAM中企业能覆盖的部分 | 战略空间评估 |
| **SOM** (Serviceable Obtainable Market) | SAM中实际可获取的份额 | 收入目标设定 |

## 估算方法

### 方法1：自上而下 (Top-Down)

从宏观经济数据逐步下钻到细分市场。

```
步骤:
1. 获取行业总规模（第三方报告、政府统计）
2. 确定细分领域占比
3. 乘以目标区域比例
4. 乘以目标客户群比例

示例（中国 SaaS 行业）:
  中国软件行业总规模: 8000亿
  → SaaS 占比: 20% → 1600亿
  → 中小型企业 SaaS: 35% → 560亿
  → 目标（华东区）: 25% → 140亿
  = SAM (可服务市场): 140亿

优势: 数据可得性高
风险: 过于宏观，分拆假设可能导致偏差
```

### 方法2：自下而上 (Bottom-Up)

从单个客户的消费金额累加。

```
步骤:
1. 确定目标客户数量
2. 估算每个客户的年消费额（客单价）
3. 相乘得到市场规模

示例（企业培训 SaaS）:
  中国中小企业数: 4000万家
  × 可能接受付费培训的比例: 5% → 200万家
  × 年均客单价: 5000元
  = TAM: 100亿

优势: 更接地气，操作性强
风险: 低估市场（忽略未覆盖的部分）
```

### 方法3：价值链推算 (Value Chain)

通过上下游数据推演行业规模。

```
示例（芯片设计行业）:
  全球芯片销售额: 5000亿
  × 芯片设计占芯片价值: 30% → 1500亿（芯片设计市场）
  × 第三方设计服务占比: 20% → 300亿（IP/设计服务市场）

适用: 上游或下游数据更易获取的场景
```

### 方法4：类比法 (Analogy)

参考成熟市场的渗透率推算新兴市场。

```
示例（中国AI编程工具市场）:
  美国开发者人数: 500万
  美国AI编程工具付费率: 15% → 75万用户
  美国市场规模: 75万 × $20/月 = $1.8亿/月

  中国开发者人数: 800万
  假设按美国1/3的付费率和1/2的客单价:
  中国TAM: 800万 × 5%付费率 × ¥50/月 = ¥20亿/月
  
适用: 新兴市场或无直接数据时
注意: "渗透率差距"和"购买力差异"是调整关键
```

## 常见问题

### 市场规模 vs 市场空间

| 概念 | 含义 |
|------|------|
| **市场规模** | 现在的市场总额（现状） |
| **市场空间** | 潜在可拓展空间（未来） |
| **渗透率** | 现有规模 / 空间 |

### 数据来源优先级

| 优先级 | 来源 | 说明 |
|:------:|------|------|
| ⭐⭐⭐⭐⭐ | 上市公司财报 | 可验证，标准化 |
| ⭐⭐⭐⭐ | 行业协会/政府统计 | 权威但可能滞后 |
| ⭐⭐⭐ | 第三方机构报告 | 方便但可能有偏见 |
| ⭐⭐ | 专家访谈/估算 | 便于交叉验证 |
| ⭐ | AI 推算 | 需标注假设条件 |

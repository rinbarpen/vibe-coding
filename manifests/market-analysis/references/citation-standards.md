# 引用规范与核查指南

## 为什么引用重要

行业研究报告的可信度建立在**可验证的数据来源**上。每条数据都需要标注来源，以便读者验证。

## 引用格式标准

### 正文内引用

```
格式1（简洁）: [来源: 机构/作者, 年份]
格式2（详细）: [来源: 报告名, 机构, 年份]
格式3（网址）: [来源: URL 简写]

示例:
根据IDC报告，2025年中国AI软件市场规模达 450 亿元 [来源: IDC, 2025]。
该行业近三年CAGR为 31% [来源: 中国AI产业白皮书, 中国信通院, 2025]。
```

### 文末来源列表

```markdown
## 参考文献

[1] IDC. *中国AI软件市场追踪报告, 2025*. https://www.idc.com/
[2] 中国信息通信研究院. *人工智能发展白皮书, 2025*. https://www.caict.ac.cn/
[3] 艾瑞咨询. *2025年中国AI行业研究报告*. https://www.iresearch.com.cn/
[4] 公司A. 2025年年度报告. https://www.example.com/annual-report
[5] 国家统计局. 2025年国民经济和社会发展统计公报. https://www.stats.gov.cn/
```

### 不同类型来源的引用

| 来源类型 | 引用要素 | 示例 |
|---------|---------|------|
| **第三方报告** | 机构 + 年份 | `[来源: IDC, 2025]` |
| **公司年报/公告** | 公司 + 年份 | `[来源: 公司A年报, 2025]` |
| **新闻文章** | 媒体 + 日期 | `[来源: 36氪, 2025-06]` |
| **政府数据** | 部门 + 年份 | `[来源: 国家统计局, 2025]` |
| **招股书** | 公司 + 招股书年份 | `[来源: 公司B招股书, 2024]` |
| **学术论文** | 作者 + 年份 | `[来源: Zhang et al., 2025]` |
| **AI 推算** | 标注假设 | `[推算: 基于IDC 2024数据外推]` |

## 引用分级标注

| 标记 | 含义 | 使用场景 |
|:----:|------|---------|
| ✅ | 可验证 | 公开来源，可通过链接或公开渠道查证 |
| ⚠️ | 推算/估计 | 基于已知数据的合理推算，标注假设 |
| ❓ | 待核实 | 信息来源不确定或存在争议 |
| 🔒 | 非公开 | 来源于付费数据库或内部数据 |

## 引用核查流程

### 交付前核查清单

```
□ 每条关键数据都标注了来源
□ 可验证的引用（✅）都可以通过公开渠道查到
□ 推算数据（⚠️）标注了假设条件
□ 无标注的关键数据 = 0
□ 来源列表格式统一、完整
□ 不同报告中同一数据引用一致
□ 没有"据估计"、"有消息称"等模糊表述
```

### 常见问题

| 问题 | 表现 | 修正 |
|------|------|------|
| **无源断言** | "行业规模超过500亿" 没有出处 | 补充 `[来源: ...]` |
| **模糊引用** | "据媒体报道…" 哪个媒体？ | 具体到 `[来源: 媒体名, 日期]` |
| **引用过时** | 引用了3年前的数据说"最新" | 更新到最近数据 |
| **推算未标注** | 使用推导数据但没说假设 | 加 `[推算: 假设说明]` |
| **引用不匹配** | 引用的来源和实际数据不符 | 核查原始来源 |
| **二次引用** | "据A引用B说…" | 尽量找到原始来源B |

## 如何验证引用

### 可公开验证的来源

```markdown
| 来源类型 | 验证方法 |
|---------|---------|
| 第三方报告摘要 | 搜索引擎查找报告标题+机构名 |
| 公司年报数据 | 公司官网投资者关系页面 |
| 政府统计数据 | 国家统计局/各部委官网 |
| 新闻数据 | 搜索新闻标题+媒体名+日期 |
| 招股书数据 | 交易所官网信息披露页面 |
```

### 不可直接验证的处理

如果某个数据点无法找到原始来源：

```markdown
方案1: 替换为可验证的相近数据
  ❌ "行业规模500亿" [来源: 某内部报告]
  ✅ "行业规模450亿" [来源: IDC, 2025]

方案2: 明确标注为推算并说明假设
  ✅ "预计行业规模500亿" [推算: 基于IDC 2024年380亿数据, 假设增长率31%]

方案3: 删除该数据
  如果既找不到来源也无法合理推算，宁可删除也不要无源断言
```

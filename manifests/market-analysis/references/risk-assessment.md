# 风险评估框架：从行业到公司

## 核心理念

**投资的风险不是波动，而是永久性资本损失。**
好的分析不只是识别机会，更要系统性地识别风险。

---

## 三层风险框架

```
                    ┌─────────────────────────┐
                    │  第一层：宏观风险         │
                    │  你无法控制的风险         │
                    └──────────┬──────────────┘
                               ↓
                    ┌─────────────────────────┐
                    │  第二层：行业风险         │
                    │  影响整个行业的事件       │
                    └──────────┬──────────────┘
                               ↓
                    ┌─────────────────────────┐
                    │  第三层：公司风险         │
                    │  这家公司特有的风险       │
                    └─────────────────────────┘
```

---

## 第一层：宏观风险

### 风险清单

| 风险类型 | 具体风险 | 影响 | 监控指标 |
|---------|---------|------|---------|
| **利率** | 利率上升→成长股估值压缩 | AI软件公司估值受影响大 | 10年期国债收益率、美联储利率决议 |
| **地缘政治** | 中美关系紧张→芯片出口管制 | 算力供给受限 | 出口管制清单、贸易政策 |
| **经济周期** | 经济衰退→企业IT预算收缩 | AI采购推迟 | GDP增速、企业信心指数 |
| **汇率** | 人民币/美元波动 | 有海外业务的公司 | 汇率走势 |
| **资本市场** | 融资环境收缩 | 亏损公司融资困难 | VC/PE投资额、IPO窗口 |

### 宏观风险评分

```markdown
| 风险 | 概率(1-5) | 影响(1-5) | 综合评分 | 对冲方式 |
|:----:|:--------:|:---------:|:--------:|---------|
| 利率上升 | 3 | 4 | 12 | 选择盈利公司 |
| GPU管制升级 | 3 | 4 | 12 | 关注国产替代 |
| 经济衰退 | 2 | 3 | 6 | 选择高现金流公司 |
| 融资收紧 | 3 | 3 | 9 | 选择现金充裕公司 |

关注重点: 利率和GPU管制是AI行业的两个最大宏观风险
```

## 第二层：行业风险

### 从行业研究中提取风险

行业研究的每个维度都可以推导出风险：

| 行业研究维度 | 可能的风险 | 影响对象 |
|-------------|---------|---------|
| **市场分析** | 增速放缓、渗透率见顶 | 全行业 |
| **竞争格局** | 价格战、新进入者、替代品 | 在位者 |
| **产业链** | 上游涨价、下游压价 | 中游 |
| **技术趋势** | 技术路线被颠覆、被替代 | 押错路线的公司 |
| **政策环境** | 监管收紧、政策转向 | 全行业或特定细分 |

### 示例：AI软件行业风险推导

```markdown
## 从行业研究推导行业风险

### 1. 竞争风险
来源: 行业研究发现CR3=55%，百度阿里腾讯都在重投入
风险: 如果巨头开始打价格战，中小AI公司利润率受严重挤压
概率: 中等
影响: 高
监控: 头部公司AI产品定价趋势

### 2. 技术颠覆风险
来源: 技术评估发现开源模型快速追赶
风险: 开源模型达到闭源水平→LLM基础层商品化→利润被压缩
概率: 高
影响: 高（对模型层）、低（对应用层）
监控: 开源模型在关键基准上的表现

### 3. 政策风险
来源: AI治理法实施
风险: 合规成本上升，某些应用场景受限
概率: 中高
影响: 中
监控: 监管细则出台、执法案例
```

## 第三层：公司特有风险

### 风险识别框架

```markdown
## 公司风险检查清单

### 业务风险
□ 收入过于依赖单一客户？（前5大客户占比 > 50%）
□ 收入过于依赖单一产品？（该产品收入 > 70%）
□ 客户流失率是否在上升？
□ 定价权是否在下降？（ASP趋势？）
□ 是否面临重大诉讼或监管调查？

### 技术风险
□ 核心技术的护城河是否在缩小？
□ 是否有被新技术替代的风险？
□ 研发投入是否低于行业平均水平？
□ 关键技术人才是否流失？

### 财务风险
□ 公司是否依赖持续融资维持运营？
□ 负债率是否过高？（净债务/EBITDA > 4x）
□ 应收账款增速是否远高于收入增速？（放松收款条件）
□ 商誉是否占总资产比重过高？（收购风险）
□ 股权稀释率是否过高？（年稀释 > 3%）

### 管理层风险
□ 依赖核心创始人？（如果创始人离开会怎样？）
□ 管理层薪酬是否和股东利益冲突？
□ 管理层是否有不良资本配置历史？
□ 是否有内幕交易或关联交易问题？

### 治理风险
□ 股权结构是否过于集中或分散？
□ 独立董事是否真正独立？
□ 是否有争议的关联交易？
□ 信息披露是否充分和及时？
```

## 概率-影响矩阵

### 风险分类

```markdown
                    影响程度
                  低        高
             ┌──────────┬──────────┐
         高  │  监控即可  │  关键风险  │
    发生     │  定期检查  │  必须管理  │
    概率     ├──────────┼──────────┤
         低  │  忽略     │  设置预警  │
             │  不值得花时间│  触发时行动  │
             └──────────┴──────────┘
```

### 关键风险 vs 可管理风险

| | 不可控 | 可控 |
|:----:|:------:|:----:|
| **知道** | 重点监控 | 主动管理 |
| **不知道** | 未知黑天鹅 | 努力发现 |

## 情景分析

### 三情景框架

```markdown
## 情景分析：AI软件龙头公司

### 基准情景 (概率: 50%)
- AI采用率继续提升→公司收入增长30%+
- 利润率改善但不显著
- 股价: 当前水平 ±15%

### 乐观情景 (概率: 25%)
- AI Agent商业化爆发→收入增长加速到50%+
- 规模效应开始显现→利润率大幅改善
- 股价: 当前水平 +50%+
- 触发条件: 出现杀手级AI应用

### 悲观情景 (概率: 25%)
- 经济衰退→企业IT预算收缩
- 开源模型竞争加剧→价格战
- 增长放缓到10-15%，利润下滑
- 股价: 当前水平 -30%+
- 触发条件: GPU管制升级 + 经济衰退叠加
```

## 监控触发点（Red Flag / Green Flag）

### 行业层面触发点

```markdown
| 信号 | 对情景的影响 | 关注频率 |
|------|:-----------:|:--------:|
| 🟢 企业AI采用率 > 60% | 基准→乐观 | 季度 |
| 🔴 主要客户减少AI预算 | 基准→悲观 | 每月 |
| 🟢 LLM推理成本再降50% | 利好应用层 | 每季度 |
| 🔴 GPU出口管制进一步升级 | 全行业利空 | 随时 |
| 🟢 国内AI芯片取得突破 | 缓解供给约束 | 半年 |
| 🔴 重大AI安全事故引发严监管 | 全行业利空 | 随时 |
```

### 公司层面触发点

```markdown
| 信号 | 含义 | 行动 |
|------|------|------|
| 🟢 AI收入占比 > 30% | 商业化验证 | 强化假设 |
| 🟢 NDR > 120% | 客户粘性强 | 继续持有 |
| 🔴 核心CTO/科学家离职 | 技术风险 | 重新评估 |
| 🔴 客户流失率 > 10% | 竞争加剧 | 考虑退出 |
| 🟢 毛利率提升 > 5% | 规模效应 | 正向信号 |
| 🔴 烧钱率加快 | 财务恶化 | 关注现金流 |
```

## 风险应对矩阵

| 风险等级 | 应对方式 | 行动 |
|:--------:|---------|------|
| 🔴 **关键风险** | 规避/对冲 | 不投资或极小仓位 |
| 🟠 **重要风险** | 管理/监控 | 定期检查，设止损 |
| 🟡 **关注风险** | 观察 | 季度检查 |
| 🟢 **轻微风险** | 接受 | 不专门管理 |

---

## 关键原则

1. **风险是立体的**：宏观×行业×公司三层叠加
2. **不确定性和风险不同**：不确定是不知道结果，风险是知道可能结果的概率
3. **尾部风险不能忽视**：概率低但影响极大的事件要设预警
4. **风险不是独立事件**：多重风险可能同时发生（如利率上升+经济衰退）
5. **最大的风险是你不知道的风险**：保持开放心态，持续更新风险评估

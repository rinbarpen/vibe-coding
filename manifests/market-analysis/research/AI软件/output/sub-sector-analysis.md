## 一、细分赛道全景扫描


## 🥇 Tier 1：最优先关注

### 1. AI Agent基础设施与平台

**一句话逻辑**：Agent从原型走向企业级商用的过程中，最确定受益的是"卖铲子"的——Agent框架、MCP工具链、监控评估平台。

| 维度 | 得分 | 说明 |
|:----|:----:|:------|
| 市场空间 | ⭐⭐⭐⭐ | 2026年全球Agent相关软件市场预计~80亿美元，2028年~300亿 [推算: Gartner趋势外推] |
| 增速 | ⭐⭐⭐⭐⭐ | Agent相关投入年增100%+（2024-2026） |
| 确定性 | ⭐⭐⭐ | 方向明确但具体路径有变数 |
| 竞争格局 | ⭐⭐⭐⭐ | 早期市场，格局未定，先发优势重要 |
| 爆发临近度 | ⭐⭐⭐⭐⭐ | **6-12个月内可观察到拐点** |

**爆发时间线：**
```
2026H1 ──── 2026H2 ──── 2027H1 ──── 2027H2 ──── 2028
  框架标准化   首个企业标杆案例   规模化部署   工具链成熟   爆发高峰
  ↑MCP协议定稿   ↑财富500强部署    ↑Agent收入占比>10%
```

| 候选标的 | 类型 | 定位 | 爆发信号 |
|:---------|:----:|:-----|:---------|
| **Microsoft (MSFT)** | 全球巨头 | Copilot Studio + Azure AI Agent | Agent收入在Azure AI中占比 |
| **字节跳动** | 中国平台 | 扣子(Coze) + 飞书AI Agent | 企业Agent部署案例数 |
| **百度** | 中国平台 | 百度智能体平台 + 文心Agent | 智能体调用量增速 |
| **LangChain** | 私有/未上市 | Agent框架全球标杆 | 融资轮次/估值 |
| **CrewAI / AutoGPT** | 开源项目 | 多Agent编排 | GitHub Star增长 / 商业化进展 |

> **关键验证信号**：MCP协议在2026年下半年的企业采用率。如果主流云厂商全面支持MCP，Agent生态将进入爆发期。

### 2. AI+垂直行业应用（医疗/法律/金融）

**一句话逻辑**：通用AI能力趋于同质化，真正的壁垒在行业know-how和数据。拥有行业私有数据+合规门槛的公司最安全。

| 维度 | 得分 | 说明 |
|:----|:----:|:------|
| 市场空间 | ⭐⭐⭐⭐ | 行业AI应用市场占AI软件~35%，规模~300亿美元(2025E) |
| 增速 | ⭐⭐⭐⭐ | 垂直AI SaaS增速40-60% |
| 确定性 | ⭐⭐⭐⭐ | 行业需求真实，ROI可量化 |
| 竞争格局 | ⭐⭐⭐ | 碎片化，但先发者数据壁垒明显 |
| 爆发临近度 | ⭐⭐⭐⭐ | **部分细分已爆发，多数在2027前** |

**爆发时间线：**
```
AI编程(已爆发)
  └─ GitHub Copilot 2024收入~20亿美元, 2026预计~50亿+
AI医疗(2026-2027)
  └─ 医学影像AI在中国已获批NMPA三类证~80张, 2026进入渗透加速期
AI法律(2027-2028)
  └─ 合同审查/法律检索等场景正在验证, 合规要求推动采用
AI金融(已局部爆发)
  └─ 智能投顾/风控模型已成熟, 生成式AI客服在加速
```

| 候选标的 | 细分 | 定位 | 爆发时间 |
|:---------|:----|:-----|:--------:|
| **金山办公 (688111)** | AI办公 | 国内WPS AI，订阅制，高粘性 | **已开始**，2026H2加速 |
| **科大讯飞 (002230)** | AI语音+教育 | 星火大模型+教育AI硬件 | **现在-2027** |
| **恒生电子 (600570)** | AI金融 | 金融AI应用+大模型 | 2026H2-2028 |
| **同花顺 (300033)** | AI金融 | iFinD AI投研+智能投顾 | **现在-2027** |
| **Palantir (PLTR)** | AI数据 | AIP平台，企业AI操作系统 | 2026-2028 |
| **ServiceNow (NOW)** | AI企业流程 | Now Assist AI | **现在** |

> **关键逻辑**：AI编程已证明垂直AI商业化的可行性（GitHub Copilot 2024年ARR~20亿美元）。下一个复制这个路径的垂直行业大概率是医疗和金融。

## 🥉 Tier 3：观察名单

### 5. 基础模型层（LLM训练）

**判断**：资本消耗战，商业模式不清晰。OpenAI/Anthropic估值虽高但还在亏损，中国模型创业公司面临淘汰赛。**不建议作为投资标的考虑**，除非有极强的判断认为某家公司能赢。

**中国模型公司淘汰赛格局**：
```
第一梯队（存活概率高）: 智谱AI、百川智能、月之暗面
第二梯队（融资困难）: MiniMax、零一万物、阶跃星辰
边缘（危险）: 大多数小型模型创业公司
```

### 6. AI PaaS/云平台AI能力

**判断**：这是云巨头的战场（Azure AI/Vertex AI/AWS Bedrock/阿里云PAI），AI功能只是云服务的增值项，不是独立产品。看好云巨头整体，但单纯的"AI PaaS"子赛道缺乏独立投资逻辑。

## 三、我的判断

### 最清晰的"爆发"路径

**AI Agent基础设施 > AI+垂直行业应用** 是目前确定性最高的两条路径。

具体来说：

```
最值得深度研究的标的：
  
  全球视角:
  ─ Microsoft (MSFT): 拥有最完整的AI堆栈（模型+平台+应用+Agent）
  ─ ServiceNow (NOW): AI+企业流程，NDR>120%，订阅模式成熟
  
  中国视角:
  ─ 金山办公 (688111): WPS AI，中国最像Microsoft 365的故事
  ─ 科大讯飞 (002230): 语音+教育AI双轮，星火模型加持
  ─ 恒生电子 (600570): 金融AI+大模型，行业know-how壁垒高
```

### 时间线

```
现在（2026Q3）：
  → AI编程赛道已爆发（Copilot/AWS CodeWhisperer）
  → AI金融局部爆发（智能投顾/风控）

2026Q4 - 2027Q1：
  → AI Agent早期企业案例出现
  → 医疗AI NMPA三类证持续获批

2027 - 2028：
  → AI Agent规模化部署
  → 法律AI拐点
  → 推理成本再降50%+ → 更大规模的企业采用
```

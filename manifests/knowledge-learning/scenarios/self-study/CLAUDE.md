# CLAUDE.md — Self-Study Scenario

## Focus

自主学习模式：无外部约束，以兴趣驱动、探索为导向的深度学习。

## Commands

| Command | Description |
|---------|-------------|
| `/learn <topic>` | 自定节奏学习会话 |
| `/study <material>` | 深入钻研特定材料 |

## Scenario Rules

- 学习节奏由用户自定，无硬性截止日期
- 重点在于兴趣导向的深度理解和知识连接
- 推荐使用费曼技巧检验理解深度
- 鼓励跨材料探索和 `[[wiki-link]]` 扩展阅读
- 每隔 3-5 天自动触发一次 `/review`

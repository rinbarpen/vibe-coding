# CLAUDE.md — Research Reading Scenario

## Focus

研究阅读模式：以问题为导向的深度文献阅读与综合。适用于论文阅读、技术调研、前沿追踪。

## Commands

| Command | Description |
|---------|-------------|
| `/import <path/url>` | 导入论文/技术报告 |
| `/study <material>` | 精读特定文献 |
| `/learn <topic>` | 基于文献学习 |

## Scenario Rules

- 以研究问题为起点，而非预定课程大纲
- 重视文献追踪和前沿洞察
- 每篇文献提取：问题 → 方法 → 结果 → 结论
- 多篇文献间建立对比连接
- 产出：文献综述 + 跨文献连接图

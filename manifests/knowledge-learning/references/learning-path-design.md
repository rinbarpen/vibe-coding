# 学习路径设计 (Learning Path Design)

## 概述

学习路径是将一个知识域从入门到掌握的结构化路线图。好的学习路径包含前置知识、核心内容、实践项目和评估机制。

## 设计步骤

### 1. 领域映射

将目标领域拆解为知识树：
- **核心概念**: 必须掌握的基础概念
- **层级关系**: 哪些概念是其他概念的前置
- **依赖图**: 概念间的依赖关系

### 2. 材料匹配

为每个概念匹配学习材料：
- PPT/课本: 系统化理论学习
- 视频: 可视化理解
- 文章: 补充视角
- 习题: 实践检验

### 3. 阶段划分

```
Phase 1 — 基础 (入门)
  目标: 掌握核心概念和术语
  产出: 概念笔记 + 知识图谱
  材料: 课本前 3 章 + 入门视频

Phase 2 — 深入 (构建)
  目标: 理解原理和方法
  产出: 综合笔记 + 闪卡
  材料: 课本进阶章节 + 论文

Phase 3 — 实践 (应用)
  目标: 解决实际问题
  产出: 项目作品 + 习题集
  材料: 项目文档 + 练习

Phase 4 — 综合 (精通)
  目标: 跨领域连接
  产出: 综合报告 + 创新方案
  材料: 前沿论文 + 多材料综合
```

### 4. 评估标准

- **概念掌握**: 能否用费曼技巧解释
- **实践能力**: 能否独立完成项目
- **知识连接**: 能否建立跨概念/跨材料连接
- **复习稳定性**: 卡片是否达到稳定间隔 (≥21 天)

# 试卷生成器 (Exam Generator)

## 概述

从已有学习材料自动生成试卷和习题。核心设计：**每道题必须有源材料支撑，难度可配置，知识点排布可控**。

## 难度体系

### 三档难度定义

| 难度 | 认知层级 (Bloom) | 题型偏好 | 来源要求 |
|------|-------------------|----------|----------|
| Easy | 识记、理解 | 选择、判断、填空 | 单来源直接引用 |
| Medium | 应用、分析 | 简答、计算、短论述 | 1-2 个来源综合 |
| Hard | 评价、创造 | 综合论述、设计题 | 多来源跨章节综合 |

### 难度分布配置

```
# example: 综合测试 mixed 模式
total: 50
distribution:
  easy:   30% (15题) — 选自单页PPT/单段落
  medium: 40% (20题) — 跨页/跨小节综合
  hard:   30% (15题) — 跨章/跨材料综合
```

## 题型模板

### 选择题 (Choice)
- 4 个选项：1 正确 + 3 干扰
- 干扰项来源：**常见混淆概念**（来自笔记中的 confusions 字段）

### 填空题 (Fill)
- 挖空关键术语/公式/数值
- 空位用 `____` 标记

### 简答题 (Short Answer)
- 要求用自己的话解释概念
- 评分标准：定义准确度 + 示例质量 + 表达清晰度

### 综合题 (Essay)
- 跨概念/跨材料的综合应用
- 要求展示推理过程
- 评分标准：完整性 + 逻辑性 + 创新性

## 知识点覆盖

- 自动从笔记中提取知识点列表
- 试卷生成时检查覆盖率（默认 ≥ 80%）
- 知识点可以手动指定或排除
- 未覆盖的知识点自动报告

## 答案与解析

每道题生成：
- **标准答案**: 精确答案（来源引用）
- **解析**: 为什么是这个答案（推理过程）
- **干扰项解析**: （选择题）每个干扰项的混淆来源

# 灵能知识参考

创作涉及精神力量、超能力或心智干预元素时，可参考本文件以保持体系的严谨性。

## 定义与本质

- **灵能 (Psionics)**：指通过精神力量直接干预物质世界或感知超感官信息的能力。通常被视为“心智胜过物质” (Mind over Matter)。

## 常见灵能学科 (Disciplines)

| 学科 | 能力描述 |
|------|----------|
| **心灵感应 (Telepathy)** | 读取、传输思想，甚至控制他人心智。 |
| **念力 (Telekinesis)** | 通过意念移动、操纵或破坏物体。 |
| **发火术 (Pyrokinesis)** | 激发分子运动产生高温或火焰。 |
| **预知 (Precognition)** | 感知未来的片段或可能性。 |
| **透视 (Clairvoyance)** | 感知远方或被遮挡的场景。 |
| **感物术 (Psychometry)** | 通过触摸物体读取其历史或残留记忆。 |

## 能量来源

- **大脑潜能**：生物进化的极致，大脑未开发区域的觉醒。
- **宇宙能量**：从宇宙背景辐射或高维空间汲取的能量。
- **集体无意识**：从全人类或所有生物的共同精神海洋中借取力量。

## 限制与副作用

- **灵能过载 (Psychic Strain)**：过度使用会导致剧烈头痛、流鼻血、视网膜出血。
- **精神不稳定**：长期接触他人负面情绪或高维信息可能导致人格分裂或疯狂。
- **“虚空” (The Void)**：过度透支力量后可能陷入的精神枯竭状态，甚至导致灵魂消散。

## 不同流派的诠释

- **硬科幻/变异 (如 X 战警)**：解释为基因突变（X 基因），生物进化的产物。
- **太空歌剧 (如 星际大战)**：解释为弥漫在宇宙中的能量场（原力），具有一定意志。
- **黑暗奇幻 (如 战锤 40k)**：灵能者从危险的“亚空间” (Warp) 汲取能量，易受恶魔诱惑。

## 灵能辅助工具

- **放大器 (Amplifiers)**：头盔、阵列等，用于增强输出功率或感应范围。
- **抑制器 (Dampeners)**：用于限制灵能者的能力，常用于囚禁灵能罪犯。
- **灵能晶体 (Crystals)**：储存或过滤灵能能量的特殊矿石，常用于制作武器或法杖。

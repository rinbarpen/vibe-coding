# AGENTS.md

AI 创作助手（Cursor, Claude Code 等）在小说创作项目中的协作指南。

## 创作角色分工 (Subagent Roles)

在进行复杂创作任务时，建议调用具有特定倾向的 Subagent：

- **`muse` (灵感家)**: 负责头脑风暴、剧情反转、世界观扩充。涉及神秘学、神话（希腊、北欧、中式、日式）、修仙或异世界元素时，参考 `references/` 下的相关知识文件。
- **`logician` (逻辑检查员)**: 负责剧情一致性检查、伏笔追踪、力量体系平衡。
- **`stylist` (文字修辞师)**: 负责遣词造句、氛围烘托、对话润色。
- **`editor` (主编)**: 负责整体节奏控制、章节结构优化、大纲维护。审核世界观设定时，可参考 `references/` 下的神秘学与神话知识以校验一致性。

## 核心创作流 (Vibe Writing)

1. **灵感 (Ideate)**: 在 `drafts/` 记录灵感碎片，调用 `muse` 进行扩展。
2. **大纲 (Outline)**: 在 `outline/` 维护主线与支线，由 `editor` 审核结构。
3. **草拟 (Draft)**: 在 `chapters/` 编写初稿，保持流畅度，不纠结细节。
4. **逻辑校验 (Verify)**: 调用 `logician` 扫描新章节与 `characters/` 及 `world/` 的冲突。
5. **润色 (Polish)**: 调用 `stylist` 对重点段落进行风格化处理。
6. **归档 (Archive)**: 完成章节后更新 `CLAUDE.md` 中的进度。

## 自动化任务

- **人设一致性**: 每次更新 `chapters/` 后，AI 应自动核对 `characters/` 中的关键属性。
- **伏笔库管理**: AI 维护一个隐藏的伏笔列表，提醒作者在后续章节回收。
- **字数统计**: 自动生成每日创作进度报告。

## 创作规范

- **禁止 OOC**: 严禁 AI 改变既定角色的性格基调。
- **风格统一**: 保持全书叙述视角（第一/第三人称）的一致性。
- **敏感词过滤**: 自动识别并提示可能存在的违规内容。

## 维护

- 定期使用 `vibe-novel-audit` 检查世界观设定是否出现逻辑断层。
- 确保 `CLAUDE.md` 始终反映最新的剧情进度。

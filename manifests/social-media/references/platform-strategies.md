# 各平台运营策略参考

## 微信公众号运营要点

### 内容策略
| 类型 | 占比 | 特点 |
|------|:----:|------|
| 干货教程 | 40% | 提供实用价值，转发率高 |
| 行业观点 | 30% | 建立专业形象 |
| 案例拆解 | 20% | 具象化，易理解 |
| 互动/活动 | 10% | 提升粉丝活跃度 |

### 发布建议
- **最佳时间**：早 8-9 点、中 12-13 点、晚 8-10 点
- **频率**：每周 2-4 篇
- **标题技巧**：数字、悬念、痛点、对比（如 "3 个方法"、"别再...了"）

### 数据指标参考
| 指标 | 健康值 | 优秀值 |
|------|:------:|:------:|
| 打开率 | 2-5% | >8% |
| 分享率 | 0.5-2% | >3% |
| 完读率 | 30-50% | >60% |

## 小红书运营要点

### 内容策略
| 类型 | 特点 | 适用场景 |
|------|------|----------|
| 测评 | 真实体验+图文对比 | 产品推荐 |
| 教程 | Step-by-step | 技能分享 |
| Vlog | 生活记录 | 人设建设 |
| 合集 | 清单式整理 | 收藏率高 |

### 爆款公式
```
优质封面 + 关键词标题 + 口语化正文 + 高频标签
```

### 标签策略
- 大标签（类目）：#数码 #生活
- 中标签（细分）：#效率工具 #桌面搭配
- 小标签（长尾）：#程序员好物 #极简桌面
- 每个笔记 3-5 个标签

## Twitter 运营要点

### 内容策略
| 类型 | 作用 |
|------|------|
| 价值推文 | 分享知识/经验 |
| 观点推文 | 引发讨论 |
| 互动推文 | 投票/问答 |
| 个人故事 | 建立人设 |

### Thread 数据
- 开头 3 条推文决定 80% 的留存率
- 每条推文之间间隔 2-5 分钟发布效果最好
- Thread 的互动率是单条推文的 3-5 倍

# 17 类科研图的实现配方与视觉规范

这是生成器执行契约，不是 17 个已内置的渲染引擎。每类都有独立布局、数据处理和验收方法。

## 通用审美与配色

优先白底、克制强调色、轻网格、统一字体和稳定方法配色。颜色加形状/线型双重编码；不能仅靠红绿区分。按最终排版尺寸审查标签与图例。建议 90 mm 单栏、180 mm 双栏是项目默认而非期刊硬规则，实际以目标 venue 为准。

配色组：editorial（蓝橙青紫）、contrast（高区分类别）、earth（低饱和自然色）、monochrome（灰度）。每组分别包含 categorical、sequential、diverging；方法分类、连续数值、带符号差值分别选择对应色组。自定义组合须通过 HEX 和唯一颜色校验；这不等于已通过色觉模拟或视觉审查。

## architecture — 分层组件图
- **布局**：按输入—编码—交互—输出分层；相同模块复用宽高；训练专用路径用虚线。
- **实现**：从 METHOD_SPEC 和代码提取组件、张量尺寸、边；按拓扑层布局，正交连线；导出可编辑矢量。
- **验收**：检查每条边与实际 forward 路径一致；禁止用装饰节点暗示未实现组件。
- **色组**：`categorical`

## flowchart — 泳道决策图
- **布局**：主路径垂直，异常分支侧置；决策菱形，动作圆角矩形。
- **实现**：输入 steps/branches；校验起止与分支闭合；按角色分泳道；路由连线并标注 yes/no。
- **验收**：分支条件完整，无悬空节点；灰度打印仍分辨角色。
- **色组**：`categorical`

## pipeline — 阶段与产物双轨图
- **布局**：上轨阶段，下轨数据产物；阶段等距，产物用浅底。
- **实现**：解析 stages/artifacts/dependencies；区分离线与在线；绘制阶段块与产物链接。
- **验收**：输入输出逐阶段对齐；箭头无交叉遮挡。
- **色组**：`categorical`

## algorithm — 编号算法步骤图
- **布局**：编号左对齐；循环范围框；数学符号统一，避免长段落塞框。
- **实现**：将伪代码转换为 steps/loops/conditions；展示关键状态变化；复杂度单独侧注。
- **验收**：编号和伪代码一致；符号均有定义；循环返回边清晰。
- **色组**：`categorical`

## comparison — 排序点区间图
- **布局**：默认点+区间而非密集柱形；基线低饱和，主方法强调；分面展示数据集。
- **实现**：读取 protocol/metric/method/seed/value；仅聚合同协议记录；多 seed 计算均值与样本 SD；单 seed 显示单点。
- **验收**：注明误差条含义和 n；柱形从零起；点图截断轴须标识。
- **色组**：`categorical`

## ablation — 组件差值图
- **布局**：完整模型参考线；变体按组件分组；交互项单独面板。
- **实现**：读取组件开关矩阵和 matched seed 结果；与完整模型配对求差；缺失配对标记缺失。
- **验收**：保持组件名称一致；展示所有预注册变体；单 seed 不画跨 seed 方差。
- **色组**：`diverging`

## training_curve — 均值带训练曲线
- **布局**：训练虚线、验证实线；稀疏网格，曲线末端标签；原始曲线浅色。
- **实现**：读取 run/step/split/metric；按共同 step 对齐；只在有效区间聚合；如平滑则同时保存原始值并声明窗口。
- **验收**：不外推失败 run；带区间注明 SD/CI；禁止挑选最好 seed。
- **色组**：`categorical`

## scaling — 成本性能 Pareto 图
- **布局**：资源横轴，性能纵轴；成本跨度大时显式 log；Pareto 前沿实线。
- **实现**：读取质量与真实成本/延迟；标注设备和批量；计算非支配集；拟合仅在观测范围。
- **验收**：坐标单位和尺度明确；理论 FLOPs 与实测耗时分开。
- **色组**：`categorical`

## distribution — 箱线与样本点图
- **布局**：箱线叠加固定 seed 的轻微抖动；小样本优先显示所有点。
- **实现**：读取样本级值与组；保留异常值；计算中位数/四分位；足够样本才使用密度估计。
- **验收**：报告每组 n 和异常值政策；零样本显示缺失；不要用 seed 均值假冒样本。
- **色组**：`categorical`

## scatter — 散点与残差图
- **布局**：小点半透明；拥挤时用分箱密度；拟合线独立图例。
- **实现**：读取成对观测；报告删除缺失的数量；可选回归与 bootstrap 区间，固定抽样 seed。
- **验收**：相关不表述为因果；样本单位和拟合模型注明；显示离群点。
- **色组**：`categorical`

## heatmap — 标注矩阵图
- **布局**：连续值用顺序色，带正负值用零中心发散色；缺失灰色斜线。
- **实现**：读取矩阵与标签；共享跨面板 vmin/vmax；按幅值决定数值精度；文字根据底色亮度黑白切换。
- **验收**：色条有单位；缺失不填零；重排顺序记录；禁止彩虹色。
- **色组**：`sequential`

## confusion_matrix — 计数与比例双面板
- **布局**：方格等宽；行真实列预测；共享类别顺序，计数和比例分图。
- **实现**：从逐样本标签计算计数；显式选择 row/column/all/none 归一化；零分母行标为缺失。
- **验收**：保留零支持类别；归一化规则和样本量写入 caption。
- **色组**：`sequential`

## qualitative_grid — 输入—基线—方法网格
- **布局**：列为方法行是样本；统一裁剪尺寸；失败案例独立行。
- **实现**：按预注册规则选择样本 ID；载入真实输入输出；统一全局尺度和插值；局部放大区域画框并关联。
- **验收**：不修饰实验内容；显示样本选择规则和失败例；记录裁剪坐标。
- **色组**：`categorical`

## attention — 原图与归因叠图
- **布局**：原图与 overlay 并列；透明度固定，色条独立；多方法共享尺度。
- **实现**：读取模型层/head/attribution 张量；登记聚合与归一化；对齐 token 或像素；导出原始矩阵。
- **验收**：注意力不等于因果解释；禁止逐图独立拉伸造成误导；标注方法参数。
- **色组**：`sequential`

## timeline — 双向里程碑时间线
- **布局**：真实时间比例；交错标签避免拥挤；期间用条带。
- **实现**：将时间转统一时区；按真实时间定位；解析事件与持续区间；密集事件分行。
- **验收**：不得用等距节点伪装时间间隔；每个事件关联来源。
- **色组**：`categorical`

## map — 投影分级空间图
- **布局**：中性底图；连续变量顺序色；边界细线；图例和比例尺留白。
- **实现**：读取地理数据及 CRS；显式投影；连接区域 ID；缺失区域灰色；从投影计算比例尺。
- **验收**：经纬度非等距单位；披露投影与分箱；区域缺失和零值分开。
- **色组**：`sequential`

## concept_illustration — 机制概念分镜
- **布局**：最多三层视觉层级；统一透视；标签后期矢量叠加；留白优先。
- **实现**：将已批准机制写成实体/关系/禁止暗示清单；先布局线稿；图像后端只绘制概念素材；后期加标签与箭头。
- **验收**：标明示意图；科学关系人工复核；不生成伪实验样本；记录模型、提示词和素材许可。
- **色组**：`categorical`

## GPT 双版本路线（覆盖上述五类旧后端）

Architecture、Flow、Pipeline、Algorithm、Concept 使用 `gpt-image` 生成视觉稿；可编辑版本交给 GPT 根据同一已批准语义规格设计 SVG，使用 ppt-master 原生形状导出器生成 PPTX。SVG 留档为中间源码，不以整页 SVG 图片或位图冒充可编辑 PPTX。文字、模块、箭头、图例应分别可编辑；保留调色板与字体设置。逐页审查标签、连线方向、分支和循环，与视觉稿分别核对事实，不要求逐像素一致。

记录提示词、实际模型身份、输入规格、SVG、PPTX、预览及审查日志；缺少宿主模型绑定时标记 `blocked_backend_unavailable`。此 scaffold 定义编排契约，不内置模型 API 客户端。数据图仍由真实数据和绘图代码生成，禁止图像模型代画数值结果。

# Deep Research Guide

## 概述

ARS deep-research 是一个 13-agent 深度研究团队，覆盖从问题提出到研究报告的完整过程。

## 7 种模式

### full（完整深度研究）
- 13 个 agent 全部参与
- 产出：完整研究报告（APA 7.0 格式）
- 适合：需要全面深入研究的课题

### quick（快速简报）
- 精简流程，快速产出
- 产出：研究简报
- 适合：快速了解一个方向

### paper-review（论文评审）
- 聚焦论文分析和评估
- 产出：结构化评审报告
- 适合：评审单篇论文

### lit-review（文献综述）
- 系统文献搜索和综述
- 产出：文献综述章节
- 适合：论文中的 related work

### fact-check（事实核查）
- 验证具体声明和引用
- 产出：核查报告
- 适合：投稿前最后验证

### socratic（苏格拉底式引导）
- 对话式研究引导
- 帮助理清研究思路和方向
- 适合：不确定研究方向时

### systematic-review（系统综述）
- PRISMA 合规的系统综述
- 含 meta 分析支持
- 适合：需要完整系统综述的场景

## 推荐工作流

```
不确定研究方向 → socratic → 确定方向
                    ↓
了解领域       → quick / full → 理解现状
                    ↓
写论文时       → lit-review → related work 章节
                    ↓
投稿前         → fact-check → 最终验证
```
